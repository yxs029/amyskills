# 微信公众号文章违禁词与法规检查 (WeChat Article Compliance Checker)

本技能用于帮助用户检查微信公众号文章中的违禁词和违规表达，依据《广告法》、《微信公众平台运营规范》等法规，自动识别风险内容，并生成标红检查报告和替换后的合规版本。

## 适用场景

- 用户提供了一篇公众号文章（如 Word 文档），要求检查是否有违禁词。
- 用户需要将文章中的违禁词标红并生成检查报告。
- 用户需要一版替换掉违禁词的干净/合规文章。

## 工作流程

当用户要求检查文章违禁词时，请按照以下步骤执行：

### 1. 读取文章与违禁词规则
- 读取用户提供的文章内容（支持 `.docx`、`.md` 或纯文本）。
- 参考本技能附带的违禁词规则库 `references/banned_words_checklist.md`，了解当前的违禁词分类和替换建议。

### 2. 执行全面检查
- 逐段分析文章内容，找出所有匹配或疑似违规的词汇。
- 记录每个违规词的：原词、所在段落、违规类别、违规原因、修改建议。

### 3. 生成标红版文档 (Marked Document)
- 使用 Python 的 `python-docx` 库（如未安装需先 `pip install python-docx`）生成一份 Word 文档。
- 将文章中的违禁词部分用**红色加粗**字体标出。
- 在文档末尾附上《违禁词检查报告》表格，列出所有发现的问题及修改建议。
- 命名建议：`[原文件名]_违禁词标红版.docx`。

### 4. 生成合规版文档 (Clean Document)
- 根据修改建议，将文章中的所有违禁词替换为合规表达。
- 生成一份全新的 Word 文档，确保内容通顺且无违规风险。
- 在文档末尾附上《违禁词替换对照表》，让用户清楚知道哪些地方被修改了。
- 命名建议：`[原文件名]_合规版.docx`。

### 5. 交付结果
- 将生成的两份 Word 文档（标红版和合规版）发送给用户。
- 在回复中简要总结检查结果（如发现了多少处违规，主要集中在哪些类别）。

## 附带资源

- `references/banned_words_checklist.md`: 微信公众号违禁词与违规行为对照规则 Checklist。在进行检查前，请务必阅读此文件以获取最新的审核标准。
- `scripts/check_and_generate.py`: 提供了一个处理 Word 文档并生成标红版和合规版的参考脚本模板。你可以根据实际文章内容修改其中的段落和违规记录字典，然后运行它来快速生成文档。

## 注意事项

- 检查时不仅要进行关键词匹配，还要结合上下文进行**语义分析**，识别夸大宣传、诱导分享、绝对化用语等违规行为。
- 替换建议应尽量保持原意，同时符合客观、真实的原则。
