# 12 大字报动漫插画风格

**图片数量**: 10 张

## 风格概述

复古大字 + 漫画分镜 + 黑白/暖色调。视觉像 1980-1990 年代的宣传画或讽刺漫画——超大字号标题 + 2 块或 4 块对比分镜 + 强烈黑色描边。
典型代表:产品价值分析(传统 B2B 陷阱 vs 价格战泥潭)——超大标题 + 2 块对比分镜 + 暖色调 + 强烈黑色描边 + 文字对话泡。

## 图片结构

通常是大字标题(顶部占 1/3)+ 2 块或 4 块对比分镜(底部占 2/3)+ 黑色粗描边 + 暖色调(米黄/橘红)。
- 字体:粗黑体、超大号、有时倾斜
- 分镜:漫画风格 + 人物 + 对话泡 + 障碍标签
- 颜色:米黄/橘红/黑/灰,不用冷色

## 适合配图的主题

- 反差/对比类话题(传统 vs 现代、对 vs 错、陷阱 vs 机会)
- 警示/批判类(B2B 陷阱、伪需求、价格战、内卷)
- 商业概念通俗化(用漫画解释抽象概念)
- 任何需要'冲击力 + 警示感'的论断

## 适合配图的场景

适合调性:复古 + 警示 + 通俗。适合:商业批评、概念通俗化、对比类叙事、警示类文章。不适合:严肃学术、温情故事、纯技术。

## 备注

本类适合做'开篇冲击图'或'核心论点图',视觉上有 80-90 年代宣传画感,能瞬间抓住读者注意力。
