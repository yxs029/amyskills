# 06 现代生活化插画

**图片数量**: 5 张

## 风格概述

现代插画风,蓝橙暖色调,半写实人物 + 真实场景。
本类实际只有 5 张,主要是 ecosystem_moat(iPhone 上市排队)、getihu_1981(个体户 1981)、jingdong 618(京东)、jobs_crisis(职业危机营销)——风格偏'现代商业插画',有真实人物但带插画化处理。

## 图片结构

通常是写实风格的人物群像 + 真实建筑 + 手持产品。
背景是真实城市街道,色调偏蓝橙(蓝天 / 暖色建筑 / 暖色皮肤)。
整体接近商业杂志插画或 Apple 营销视觉。

## 适合配图的主题

- 标志性产品发布 / 商业时刻(iPhone 上市、排队现象)
- 平台 / 制度 / 商业复盘(ecosystem 概念视觉化、个体户合法化、京东 618)
- 商业现象复盘(首发、抢购、消费者行为)
- 写实风格的产品 / 品牌叙事

## 适合配图的场景

适合调性:写实 + 现代 + 商业大片感。适合:产品发布复盘、商业现象分析、消费者行为、品牌故事。不适合:抽象模型、数据图表、技术架构。

## 备注

本类内容较少(5 张),且混入了一些其他风格图。选图时注意:同 base64 项目的图大部分在 02_现代深色信息图(京东618、jobs_crisis 等)。
