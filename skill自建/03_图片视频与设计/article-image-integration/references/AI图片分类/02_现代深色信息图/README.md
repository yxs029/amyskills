# 02 现代深色信息图

**图片数量**: 77 张

## 风格概述

深色 / 蓝色 / 金色 / 紫色为主色调,现代商业信息图的'主力军'。包含多种子风格:- **3D 概念隐喻**:飞轮 / 齿轮 / 建筑 / 城市 / 网络(代表:work_flywheel / dec_article)- **历史+现代双联 + 光带连接**:时间跨度对比(代表:BSE 150 周年)- **古典数据表格**:深色 + 金/蓝细线 + 表格(代表:EVA / evu_model)- **夜猫咖啡 / 业务场景**:深色 + 暖色人物(代表:at&t、work_flywheel 部分)- **网络拓扑 / 节点**:深色 + 节点 + 光带(代表:network_effect、trust 部分)、有未来感、适合表现'连接 / 整合 / 力量 / 突破'。(77 张),跨多种商业 / 科技 / 政策主题。

## 图片结构

通常 2-3 层结构:背景是深色场景(夜空 / 城市 / 法院 / 抽象空间),中层是核心隐喻(网络节点 / 握手 / 飞轮 / 鸿沟 / 锁链 / 表格),前景是人物 + 文字标签。强光带连接不同元素,营造流动感。整体接近科技发布会 keynote 视觉或电影海报。

## 适合配图的主题

- 网络效应 / 飞轮 / 整合类(平台、生态、护城河、协同)- 制度 / 政策 / 合规类(法规、监管、整合、AT&T-时代华纳)- 商业模型 / 概念对比类(网络效应、个体户制度、jobs_crisis、target 品牌)- 数字化转型 / 科技突破类(道琼斯指数、DEC 电脑演进、work_flywheel)- **数据对比 / 表格 / 经济模型**(EVA 计算、价值定价、买grid 矩阵、cc 策略、eva_model、pva_model、research_methods、research_process_model、trust_model、expectancy_value_model 等纯 ASCII 文件名的新增项目)

## 适合配图的场景

适合调性:**科技感 + 力量感 + 未来感**。适合:科技评论、深度商业分析、政策解读、品牌史、案例复盘、整合类叙事、**B2B 销售 / ROI 模型 / 经济价值计算**。不适合:轻松随笔、生活方式、温情故事。

## 备注

本类含子风格较多,选图时注意:- 同 base64 项目的图风格一致,可做一组- 古典数据表格类(EVA / buygrid / cc_strategy 等)适合讲 B2B 销售 / 价值定价- 历史+现代双联类(BSE 150 年)适合讲'百年企业'主题
