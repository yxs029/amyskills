# 13 黑色背景赛博线条动漫

**图片数量**: 30 张

## 风格概述

赛博朋克线条漫画风,纯黑背景 + 青色/黄色霓虹线框 + 半写实人物 + 信息图块。
视觉像黑客帝国 / Cyberpunk 2077 风格,带有赛博科技感,但人物和场景是动漫化的,不写实。
典型代表:CC 策略四大核心要素(直接客户/终端用户/价值链反推/联合决策方案/赋能营销协同——4 块分镜 + 障碍标签)。

## 图片结构

通常是纯黑背景 + 青色霓虹线框 + 4 块或多块分镜。
- 背景:#000 或极深蓝/紫
- 边框:青色/黄色/红色霓虹线条 + 像素角标
- 人物:半写实 + 动漫化(类似 90 年代日式动画)
- 信息块:流程箭头 + 障碍标签(红框) + 关键数据 callout

## 适合配图的主题

- B2B 战略 / 渠道策略 / 客户策略类(CC 策略、联合决策、价值链)
- 营销策略 / 商业模式类(营销协同、终端用户、价值链)
- 任何需要'未来感 + 科技感 + 战略深'的主题

## 适合配图的场景

适合调性:赛博 + 科技 + 战略。适合:B2B 战略、渠道/客户战略、商业模式。不适合:轻松生活、温情、纯历史。

## 备注

本类有 30 张,是数量第三大的分类。**核心用途**:讲'to B 商业战略'类文章的'流程图 / 战略分解图'——视觉冲击力强,信息密度高。
