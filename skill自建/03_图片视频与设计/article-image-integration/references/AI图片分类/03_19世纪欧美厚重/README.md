# 03 19世纪欧美复古

**图片数量**: 6 张

## 风格概述

19 世纪欧美风格的复古画,色调以 sepia / 棕褐 / 暖金 / 深灰为主,带历史厚重感和严肃性。 6 张,主要是 BSE 150 周年纪念图(暖色日落 + 蓝色现代 + 金色光带连接)——这个子风格跟一般'19 世纪复古'不同,带强烈的时间对比叙事。'19 世纪欧美复古'的图(qwerty、wsj、trust_infrastructure、blue_shell)实际在 04 类(ArtDeco 复古商务海报)里被归到一起——'复古 + 商务/历史叙事'这个更广主题。

## 图片结构

通常是 sepia 色调 + 历史人物群像 + 古典建筑。- BSE 150 周年子风格:左半 sepia 老照片(1875 孟买榕树下),右半蓝色现代(2025 BSE 大楼),中间金色光带从 1875 流向 2025,标注时间节点。

## 适合配图的主题

- 19 世纪商业 / 金融史(BSE 印度股市、食品安全、媒体历史)- 百年企业 / 品牌演进叙事(从'过去 vs 现在'对比视角)- 严肃叙事 / 调查报道 / 政策回溯

## 适合配图的场景

适合调性:**严肃 + 历史 + 厚重**。适合:深度历史叙事、调查报道、政策回溯、商业史复盘、品牌史的'时间跨度'对比。不适合:科技类、生活方式、轻松话题、纯情绪文章。

## 备注

本类内容较少(6 张),实际大量'复古'图被归到了 04_ArtDeco 复古商务海报(17 张)——选图时**优先看 04**。
