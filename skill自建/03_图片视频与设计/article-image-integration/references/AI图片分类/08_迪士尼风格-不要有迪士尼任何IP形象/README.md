# 08 迪士尼风格(不要有迪士尼任何 IP 形象)

**图片数量**: 4 张

## 风格概述

深色夜空 + 金色光带 + 神秘奇幻风,符合'迪士尼动画电影海报'的视觉调性(但不出现任何迪士尼 IP 角色——米老鼠/公主/城堡都不行)。
典型代表:深蓝夜空 + 金色六边形 + 金色粒子光带 + 6 块信息块(参照系/共同点/差异点/价格形象/误区/品牌资产)——视觉上像皮克斯或梦工厂的'主题感'但避开了迪士尼版权元素。

## 图片结构

通常是深蓝/紫色夜空 + 金色装饰边框 + 6-8 块信息块(围成圆形或六边形)+ 金色光带流动 + 远景山峦或城市轮廓。

## 适合配图的主题

- 品牌资产 / 品牌定位 / 品牌成长类(参照系、定位、误区、品牌资产)
- 商业概念 / 战略选择类(差异点、共识、决策)
- 任何需要'主题感 + 神秘感 + 力量感'的品牌叙事

## 适合配图的场景

适合调性:神秘 + 主题感 + 力量感。适合:品牌资产复盘、定位分析、战略选择。不适合:纪实类、纯文字、轻松话题。

## 备注

本类只有 4 张,但风格统一,适合做'开篇主题图'或'重磅理论视觉化'。**重点**:虽然视觉像迪士尼,但**不要在 prompt 里要求出现迪士尼 IP**——避版权风险。
