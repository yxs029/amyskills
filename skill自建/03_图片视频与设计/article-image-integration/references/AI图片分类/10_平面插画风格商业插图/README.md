# 10 平面插画风格商业插图

**图片数量**: 11 张

## 风格概述

现代商业插画风,半写实人物 + 现代建筑 + 信息图。整体接近商业杂志或广告插画的视觉,色彩明亮、人物写实但带插画化处理。
典型代表:外部性信息图(工厂烟囱 + 握手 + 河流污染 + 空气质量/水污染/健康损失/财产贬值等 4 类外部影响)——半写实人物 + 现代建筑 + 信息图块。

## 图片结构

通常是写实人物 + 真实建筑/场景 + 完整信息图布局。
- 人物:西装 / 商务 / 半写实,带表情和动作
- 场景:工厂 / 河流 / 城市,真实质感
- 信息块:图标 + 文字 + 颜色区分

## 适合配图的主题

- 外部性 / 公共政策 / 经济学概念(负外部性、市场失灵、公共物品)
- 企业社会责任 / ESG 报告类(环境、健康、社会影响)
- 商业现象(企业盈利 vs 社会成本)
- 写实插画风格的产品 / 品牌叙事

## 适合配图的场景

适合调性:写实 + 现代 + 商业插画感。适合:经济学概念、政策分析、ESG 报告、商业现象。不适合:科技 / 互联网 / 数据分析。
