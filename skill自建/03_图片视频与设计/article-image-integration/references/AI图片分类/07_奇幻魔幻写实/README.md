# 07 奇幻魔幻写实

**图片数量**: 10 张

## 风格概述

奇幻 / 魔幻 / RPG 风格。深色或暖色背景,带魔法光效 + 角色化场景。
包含子风格:
- **深色夜空 + 金色粒子**(代表:ip_flywheel 5 张,Hogwarts 风 + 飞行书 + 暖金粒子)
- **奇幻 RPG 双联画**(代表:evu_model 5 张,左阴云剑客 vs 右金光老者,价格战 vs 价值定价权)
视觉上史诗感强、有游戏感或电影感、适合把抽象概念(飞轮 / 价值战)视觉化。

## 图片结构

通常是深色 + 暖金粒子 / 魔幻光效,人物化或奇幻化场景(城堡 / 剑客 / 老者 / 飞行书)。
- 奇幻 RPG 风:对比双联画 + 角色对峙 + 戏剧性光影
- 夜空金粒子风:城堡轮廓 + 远景 + 流动粒子

## 适合配图的主题

- 持续积累 / 长期主义 / 飞轮类(用户增长、知识库、复利效应)
- 价值 vs 价格 / 战略选择类(值与不值、高价 vs 低价)
- 内容 / IP / 品牌沉淀类(从 0 到 1、从 1 到 N)
- 任何需要'时间累积'或'价值对决'视觉化的话题

## 适合配图的场景

适合调性:奇幻 + 长期主义 + 史诗感。适合:长期主义、复利效应、知识体系、个人成长、IP 沉淀、价值/价格对比、戏剧性商业冲突。不适合:短平快热点、纯技术架构、严肃政策。
