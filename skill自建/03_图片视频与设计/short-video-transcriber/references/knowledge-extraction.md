# 从逐字稿到知识卡片

需要把转写结果结构化入知识库时读本文。仅需逐字稿则无需阅读。

## 先做适用性判断

不是所有视频都值得拆成知识卡片。按以下判据分流：

| 内容形态 | 处置 |
|---------|------|
| 长教学视频、课程、深度访谈 | 走完整拆解，产出方法论卡片 |
| 1–3 分钟成品短视频（口播观点） | **不拆解**，作为选题与句式样本入情报层 |
| 招生/营销内容 | 入情报层；仅当补齐执行步骤后才成卡 |
| 纯资讯播报 | 只留元数据与要点，不成卡 |

**成品短视频不应被拆解。** 它们已是高度提炼的成品，在极短时长内跑完完整结构，缺乏可展开的论证过程。硬送进拆解管道只会产出比原视频更稀薄的卡片。它们的正确用途是作为「怎么讲」的范式样本，而非「讲什么」的知识来源。

## 抽象层级定级

每个提取出的知识点必须判定层级，判不准就必须找证据补齐或降级处理。

| 级 | 层名 | 判定特征 |
|----|------|---------|
| L8 | 统一理论 | 试图解释一切，常无法完全验证 |
| L7 | 经典公理 | 学科内长期未被推翻的规律 |
| L6 | 基点模型 | 规律之上的规律，跨学科成立 |
| L5 | 本质模型 | 多组经验熔炼后的上层结构 |
| L4 | 抽象模型 | 单类经验的提炼抽象 |
| L3 | 方法工具 | 经验中可迁移的部分 |
| L2 | 群体事实 | 经验总结（SOP、清单），针对某类事 |
| L1 | 个别事实 | 单个事件、单个案例 |

案例库对应 L1/L2，方法论库对应 L3–L6。L7/L8 只登记引用不展开——它们无法直接指导行动，但可作为解释 L6 何以成立的依据。

视频类内容的常见定级：长教学视频可达 L4–L5；口播观点视频多为 L4 声明级（**只有结论没有步骤，属引用位**）；操作演示类为 L3。

## 卡片字段：OPRASE 六位

每张方法论卡片按 OPRASE 递归展开，六位任一空缺即为不合格卡片，必须回原文补证据或降级为引用位素材。

| 位 | 卡片内应填什么 | 视频源常见缺失情况 |
|----|--------------|------------------|
| O | 解决什么问题、边界在哪、达成什么才算解决 | 通常有 |
| P | 用了哪些元思维、在八级阶梯的哪一级、挂哪些工具 | 通常可判定 |
| R | 使用前需要哪些前置信息与资源 | 常缺 |
| A | 执行步骤，含每步判据 | **口播类几乎必缺** |
| S | 输出物形态与验收标准 | **口播类几乎必缺** |
| E | 失效边界、常见错误、如何迭代 | 视频源反而常有，价值高 |

**视频源在 E 位上具有独特优势。** 课堂问答、失败复盘、作者自我修正这类内容在书籍与讲义中基本缺失，而口播与访谈中常自然出现。例如讲者说「0-1 阶段可以无资源投入，但不能无思考」，或「这个方向对但买太贵」——这类话正是方法论卡片最难写的失效边界。

因此**清理转写噪声时只能标记不能删除**：「诶、对吧、然后呢」是口语废话，但夹在其中的边界条件与真实教训不可损失。

## 案例的要点级对齐

案例不能只作为整体记录挂在方法论下，必须切成「案例执行片段」，每个片段挂到方法论的具体步骤 ID 上。

粗关联（不可取）：方法论 M 有 3 个经典案例。

要点级对齐（正确做法）：方法论 M 的第 2 步，案例 C 中的做法是什么、依据什么数据判断、结果如何；第 3 步被跳过，为何跳过也未出问题。

只有做到步骤级，检索才能回答「这个方法的第二步在真实项目里通常怎么落地、有哪些不同打法」，这才是能直接支撑内容生产的知识密度。

## 溯源锚点

每个片段必须带锚点，视频源使用时间戳区间：

```
#t31.36-41.80
```

它与书籍段落区间 `#p120-135`、讲义页码 `#page9`、长图切片 `#slice03` 在数据模型上等价。锚点缺失的卡片无法核查，长期必然腐坏，**不得入库**。

## 混源原则

单一来源拆不出完整方法论，这是反复验证的结论：

| 需要什么 | 最佳来源 |
|---------|---------|
| 方法论骨架 | 讲义 PDF、拆解长图（为视觉呈现被迫把结构显式化） |
| 步骤细节与论证 | 书籍、长教学视频 |
| 失效边界与真实教训 | 课堂问答、长视频失败案例、作者自我修正 |
| 表达范式与句式 | 成品短视频 |

若某主题已有配套讲义或他人拆解长图，应先用它们取骨架，再回长内容取血肉，而非从头逐章硬拆。
