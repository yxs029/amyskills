## 实际示例（E2E-001）

### 标题
```
AI提单-文档库-E2E端到端：核心浏览流程Happy Path，弹窗未弹出且展开全部失效
```

### 描述

```
前置：（什么条件下才会出现缺陷？）
SRMPRO文档库模块，已登录admin账号后访问文档库页面（https://test.esicint.com/SupplierManagement/newDocument），页面统计卡片正常显示数据（文档类型总数53、已上传文档4747、即将过期0、已过期文档28），搜索功能正常可用。

问题链接：https://test.esicint.com/SupplierManagement/newDocument
用户账号：admin / Esic@2024
供应商账号：无

步骤：（回想一下缺陷产生的操作步骤）
1. 以admin账号登录后访问文档库页面
2. 读取4张统计卡片，数据正常显示（文档类型总数=53、已上传文档=4747、即将过期=0、已过期文档=28）
3. 验证卡片数值非空非0，4张卡片中3张有数据
4. 搜索框输入"ISO"并回车，过滤后得到5行结果
5. 验证可见行包含"ISO"，采样5行中4行含ISO，占比80%
6. 点击分段器"即将过期"，叠加过滤
-
问题：（具体问题描述，可以放在步骤中）
7. 验证叠加过滤后行数：ISO搜索结果5行 + "即将过期"叠加过滤后 → 行数变为0
   [📷 嵌入截图: E2E-001_step7_ISO_即将过期叠加.png]
8. 点击"展开全部"按钮 → clicked=True，但行数仍为0
9. 展开后验证子节点出现 → 展开后行数0，没有任何子节点出现
   [📷 嵌入截图: E2E-001_step9_展开全部后.png]
10. 点击第一行文档类型节点 → click=None，弹窗未弹出（modal=False）
11. 验证弹窗标题 → 标题为空字符串
    [📷 嵌入截图: E2E-001_step11_弹窗打开.png]
12. 弹窗搜索框输入关键词 → 搜索功能未触发（搜索=False）
-
期望：（正常功能是什么样的？）
1. 在叠加过滤结果为0行时，点击"展开全部"按钮，应能正常展开所有文档类型节点，显示完整的文档类型树
2. 点击任意文档类型节点，应弹出该文档类型的详情弹窗，弹窗应包含：标题（文档类型名称）、搜索框、文档列表、分页组件
3. 弹窗搜索框应可输入关键词进行搜索过滤

定位：（推断出问题的原因是什么？）
根因推断：当叠加过滤条件（ISO搜索 + 即将过期分段器）导致结果集为空（0行）时，前端组件状态进入异常分支：
1. "展开全部"按钮在空结果集下未能正确重置/加载完整的文档类型树，导致展开后仍为0行
2. 节点点击事件在空结果集下绑定失效（click=None），未能触发弹窗打开逻辑
3. 弹窗组件可能依赖当前列表行的上下文数据，空列表导致弹窗无法初始化（modal=False、标题为空）
4. 本质是前端对"空结果集 + 展开/点击"的边界条件处理不完善，缺少空状态下的组件降级策略
```
