# Case Study: AVPL xlsx → PRD（第一轮测试参考案例）

> 本案例是 xlsx2prd skill 第一轮测试的完整执行记录（2026-08-07），可作为后续执行时的参考模板。
> 源文件：`SRM2.0标准版_AVPL_FRD_V3.0 20221114.xlsx`

## 输入特征

| 项 | 值 |
|---|---|
| 工作表数 | 7（版本记录 / 页面流转图 / 用户故事（非强制）/ 客户&业务定位 / 业务流程 / 功能清单_V1.0 / 数据清单） |
| 图片数 | 2（页面流转图 PNG 109KB、业务流程 PNG 46KB） |
| 富文本单元格 | 13 |
| 公式单元格 | 47（数据清单 A 列 `=ROW()-3`） |
| 日期单元格 | 5（number_format `mm-dd-yy`） |
| 合并单元格 | 7（客户&业务定位 5 个 + 功能清单 2 个） |
| 字体颜色 | 6 种（0066FF / 0070C0 / 2E75B5 / 9C0006 / 9C5700 / FF0000）+ 表头白 FFFFFF（忽略） |

## Sheet 结构类型映射

| Sheet | 结构类型 | MD 转换方式 |
|---|---|---|
| 版本记录 | 纯表格 | 6 列表格（表头 row1，数据 row2-5）→ 后续提取到 PRD 文档信息 |
| 页面流转图 | 纯图片 | `{{IMAGE:图片名}}` 占位符 |
| 用户故事（非强制） | 标题 + 元信息 + 表格 | C1 富文本标题 + D2/E2/F2/H2 元信息行 + 双行表头（row4 英文 + row5 中文 `<br>` 合并）54 行数据 |

| 业务流程 | 图片 + 备注 | `{{IMAGE:}}` + M10/M11 备注（红色 span） |

| 数据清单 | 提示语 + 表格 | A1 提示语（蓝色加粗）+ 12 列表格（A 列公式显示计算值 1-47） |

## 本案例发现并修复的问题（8 个）

详见 `known_pitfalls.md` 第 9-16 条：
9. Inventory C colors set→list 生命周期冲突（统计与转换解耦）
10. 非字符串单元格丢格式（统一走 inline_md）
11. bold/color 互斥（叠加渲染）
12. title_md 普通字符串标题丢颜色（加 cell_font 参数）
13. 表头白字 FFFFFF 误报（决策：不渲染不统计）
14. Windows CRLF 行尾（输出强制 LF）
15. PRD 文档信息表列数不一致（统一 4 列）
16. Step 7 非幂等（从 raw_integrated.md 套壳）

## 执行脚本（测试目录 _convert/）

| 脚本 | 对应步骤 |
