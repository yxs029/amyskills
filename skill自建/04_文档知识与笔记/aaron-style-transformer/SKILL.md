# Aaron 化 Skill（雪松风格转换器）

## 这个 skill 干什么

**输入**：一篇 AI 生成的文章草稿，或一个写作主题。

**输出**：一篇符合 Aaron 思维模式 + 文字风格、且通过 100 分 checklist ≥ 95 分打分的文章。

**边界**：
- 只做**风格改造**和**风格写作**，不做排版、不做配图、不做合规检查。
- 只针对 **Aaron 雪松**这一个作者的风格。其他作者请另建 skill。

## 三种使用模式

### 模式 A：改稿（Transform）

用户给一篇 AI 稿 → 按 v4 思维+语言双定律改造 → 出改造版 + 评分 → 未达 95 分继续改。

### 模式 B：新写（Compose）

用户给一个主题 → 按 Aaron 骨架直接写 → 出稿 + 评分 → 未达 95 分继续改。

### 模式 C：评审（Review）

用户给一篇文章（可能是自己写的、可能是别人写的、可能是 AI 生成的）
→ 用 checklist 逐项打分 → 出评分报告 + 修改建议。

**判断模式**：
- 用户明确说"改一下"、"Aaron 化"、"降 AI 味" → 模式 A
- 用户给主题+要求（"帮我写一篇讲 X 的"）→ 模式 B
- 用户说"评审"、"打分"、"看看这篇符不符合我风格" → 模式 C

## 执行流程

### Step 0：识别文章类型（30 秒）

先判断这篇文章属于哪一类（决定用哪套开场和结构）：

1. **个人复盘 / 成长故事** → 用三段自介开场（"转眼 XX 年就这么过了..."）
2. **早期商业方法论**（IPO/最佳实践类抽象模型）→ 用"你有没有想过..."共情开场
3. **历史上的今天 + 商业概念** → 用"XXXX 年 X 月 X 日..."场景开场
4. **一人公司启示 / 反常识建议** → 用"你有没有这种感觉..."痛点开场
5. **读书笔记 / 人物传记** → 用"我不怎么看书，但这本..."引子开场

读 `references/opening_templates.md` 和 `references/style_by_article_type.md` 拿具体模板。

### Step 1：结构外科手术（10 分钟）

改造原文的**结构层**——这一步是消除 AI 模板痕迹最快的地方。

- 拆掉章节内部的所有 **1/2/3/4/5 数字维度编号**
- 改成叙述型小标题（例："情绪造窗口，跟基本面没啥关系"，不要"第一，窗口是情绪造出来的"）
- 长段落切成 **1-3 行**的短段
- 关键结论抽出来**独占一段**
- 章节骨架用 **#00-#05**（历史今天类）或**叙述章节名**（方法论类）

### Step 2：思维注入（15 分钟）—— 最重要

按 `references/thinking_four_laws.md` 依次注入：

**定律 1：坐标原点**
- 挑 1 处塞入"我在这个概念的哪一层"（"我以前对 X 的理解特别模糊""老实说我第一次听到 X 是懵的"）
- 密度：全文至少 1 处

**定律 2：跨领域迁移**
- 挑 1 处塞入"从 A 迁移到 B/C/D"（越远越好：金融→学习→婚恋 / 键盘→知识库→APP）
- 密度：全文至少 1 处

**定律 3：具体短板**
- 挑 1 处写出**可视觉化**的失败细节（不是"仍需努力"，而是"我尝试 3 次都在第二步卡住"）
- 密度：全文至少 1 处

**定律 4：主观判断+谦逊修饰**
- 挑 1 处塞"我觉得...吧""夸张点说""或许""大概"
- 密度：全文至少 1 处

### Step 3：语言染色（10 分钟）

按 `references/language_four_laws.md` + `references/aaron_lexicon.md` 遍历：

**定律 5：节奏破坏者** —— 每 3-5 句必有一个短句独占一段
**定律 6：思维路径过渡词** —— 用 5+ 个（其实/说远了/别急/说白了/换个角度/总结下来/万变不离其宗/你可能会说...）
**定律 7：轻自我调侃** —— 1 处即可（贪心/惭愧/硬着头皮/打酱油/是啊）
**定律 8：直接互动** —— 每 300-500 字 1 处（你有没有 / 你想想 / 不知道你...）

**禁用词表**（每次必检）：
- 首先 / 其次 / 再者 / 综上所述 / 由此可见 / 毋庸置疑
- 让我们一起 / 希望能对你有所帮助 / 这是一个非常好的问题
- "如春风拂面 / 似繁星点点 / 犹如画卷" 类华丽比喻

### Step 4：Checklist 评分（5 分钟）

打开 `references/aaron_checklist_100.md`，按 8 维度 100 分逐条打分：

| 维度 | 权重 | 关键项 |
|---|---|---|
| 思维定律（4×5=20 分） | 20 | 坐标原点/跨领域迁移/具体短板/主观判断 |
| 语言定律（4×5=20 分） | 20 | 节奏破坏者/过渡词/轻自嘲/直接互动 |
| 结构规范 | 15 | 章节骨架/无数字编号/叙述型小标题 |
| 加粗金句 | 10 | 密度/位置/是"颠覆句"不是"关键词" |
| 反问收束 | 10 | 章节末+全文末 |
| 具象锚点 | 10 | 精确年月日/精确数字/真实公司人名 |
| 禁用词清除 | 10 | 作文式过渡/客服话/华丽比喻 |
| 整体人味 | 5 | 读一遍是不是像 Aaron 说话 |

**合格线：≥ 95 分**。

未达 95 分：定位失分维度 → 回到对应 Step → 局部返修 → 再评。**最多迭代 3 轮**，仍不达标则输出评分报告说明原因，由用户判断是否放行。

### Step 5：输出交付物

**模式 A（改稿）交付**：
- `<原文件名>_Aaron化v<版本号>.md`：改造后正文
- `<原文件名>_Aaron评分报告.md`：checklist 打分表 + 失分点 + 迭代记录

**模式 B（新写）交付**：
- `<主题>_Aaron风格_v<版本号>.md`：正文
- `<主题>_Aaron评分报告.md`：同上

**模式 C（评审）交付**：
- `<原文件名>_Aaron评分报告.md`：只出评分 + 修改建议，不改动原文

**文件命名规则**（与其他 skill 对齐）：
- 版本号用小写 v（表示 Aaron 化动作的版本）
- 前缀在前，原文件名在后：`Aaron化_v<版本号>_<原文件名>.md`

## Checklist 使用规范

`references/aaron_checklist_100.md` 有完整的打分表。评分时必须：

1. **逐条打分，不做加总猜测**：每个子项要写出具体依据（引用原文句子）
2. **失分要注明位置**：不只是"缺跨领域迁移"，要写"缺跨领域迁移，建议在第 #03 段加入"
3. **迭代记录要留痕**：每一轮改造 → 每一轮评分，都要在评分报告里可追溯
4. **95 分是硬合格线**：不到 95 分不能交付。90-94 分是"接近达标"，用户可选择继续迭代或放行

## Constraints（硬性约束）

- **只改风格，不改事实**：所有精确年月日、公司名、数字、人名、引用必须保留
- **禁止编造私人故事**：Aaron 化用到的"我的短板"、"我以前"，如果原稿没有素材，要**从合理常识出发写一个"轻度"的**（比如"我第一次听到这词是懵的"），不要瞎编具体到时间地点的"深度"个人故事
- **保留原文附录/参考资料/YAML frontmatter**：这些不改
- **文章类型是复盘文时**：可以塞私人锚点（一堂/北辰/DISC/带娃）；**其他类型禁止**强塞
- **遇到"矛盾指令"**：如果用户说"要有人味"但又说"不要有'我'"，先按"要有人味"执行，同时在评分报告里说明取舍
- **每轮改造后必须评分**：不评分不算交付

## Output contract（每次执行必须交付）

- **改造/新写文章**：`Aaron化_v<版本号>_<主题或原文件名>.md`
- **评分报告**：`Aaron评分报告_v<版本号>_<主题或原文件名>.md`
- **迭代日志**（如果 > 1 轮）：报告末尾附"v1 → v2 → v3"的失分点变化

## 常见误区

| 误区 | 结果 | 正确做法 |
|---|---|---|
| 只做词句替换，不改思维 | AI 味依然重 | 思维四定律必须注入 |
| 强塞"带娃/一堂"到知识文里 | 违和感强 | 只在复盘文塞私人锚点，知识文用坐标原点+跨领域迁移 |
| 每章都用"我 XX 岁那年"开头 | 变成个人博客体 | 视角要根据文章类型切换 |
| 加粗金句用来标"关键词" | 变成教科书重点标记 | 加粗金句是"颠覆性总结"，不是"术语" |
| 每段都反问 | 变成质问体 | 反问用在章节末 + 全文末，中间用对话式互动 |
| 不评分就交付 | 无法验证是否合格 | 每次必须打分，未达 95 不交付 |

## 示例

**Input**：用户贴一篇 AI 生成的"IPO 窗口期"文章 800 字，说"帮我 Aaron 化"。

**Output**：
- Step 0 识别 → 历史今天+商业概念型 → 用"XXXX 年 X 月 X 日"开场
- Step 1-3 改造 → 拆数字编号 → 注入 4 定律思维 → 语言染色
- Step 4 评分 → v1 得 88 分，缺具体短板 + 跨领域迁移不够远
- Step 5 v2 迭代：加入"我 2023 年错过 AI 窗口"的具体短板 + 把 4 层准备迁移到婚恋
- v2 评分 96 分 → 合格 → 输出改造版 + 评分报告
