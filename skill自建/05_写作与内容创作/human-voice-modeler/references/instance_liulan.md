# 刘澜实例（学者对位派）⭐

> **v2 第五作者实例**。基于 5+ 篇刘澜样本（含"高质量思考的地基——系统思考"等）提炼。
> 刘澜：学者对位派。古典引用 + 双向对话 + 思考题。

---

## 1. 适用边界

**什么是"刘澜味"**：
- 读书笔记、哲学课程、管理学反思
- 古典引用（爱比克泰德 / 苏格拉底 / 芒格 / 德鲁克 / 格鲁夫 / 彼得·圣吉）
- 双向对话（"我说 X，但是..." / "你听我说..."）
- 自我修正（"我刚才有一个口误"）
- **5 大子类型**：
  - 读书会预告：《系统之美》/《沉思录》/《意如万事》
  - 课程笔记：管理者三大能力 / 学习的 3H 模型
  - 经典解读：爱比克泰德的《手册》/ 斯多葛哲学
  - 反思对话：和 ChatGPT 的对话 / 和同学的对话
  - 思考题：每篇结尾的"今晚思考题"

## 4. 60 条 checklist 默认值

### 整体级 30 条

**思维层（8 条）→ 刘澜通过 7-8 条**：
- ✓ 主题角度是对位（必用）
- ✓ 至少 1 个心智模型（**必用经典模型**：管理者三大能力 / 3H / 要素连接目标）
- ✓ 至少 1 个跨域类比（**必用 3+ 个**：古希腊 + 硅谷 + 古典）
- ✓ 至少 1 个时间纵深（古典时空）
- ✓ 至少 1 个哲学追问（**必用 3 次"为什么"**）
- ✓ 至少 1 个反常识判断（偶尔）

**重点层（6 条）→ 刘澜通过 4-5 条**：
- ✓ 自我复盘（通过"我刚才有口误" / "我没读懂"）
- ✓ 自我批评（"我没想到" / "我想到了它没想到的地方"）
- ✗ 行动指南（不写"你应该"）
- ✓ 数字锚定（"2026 年 3 月 1 日" / "875 次"）
- ✗ 至少 1 个心智模型反复用（不主用反复）

**语言层（8 条）→ 刘澜通过 5-6 条**：
- ✓ 核心词（"系统思考" / "要素、连接、目标" / "经典模型"）
- ✓ 反问 3+（"为什么？" "你知道吗？"）
- ✓ 引用权威 5+（**必用经典**：爱比克泰德 / 芒格 / 苏格拉底 / 德鲁克）
- ✓ 直接互动（"你听我说" / "你说呢" / "你能跟着我"）
- ✗ 自我调侃（克制）
- ✓ 金句 1+（偶尔）

**结构层（4 条）→ 刘澜通过 3-4 条**：
- ✓ 5-7 段式骨架（但偏长）
- ✓ 章节 ## 二级标题
- ✓ 思考题结尾（**刘澜特征**）
- ✗ 表格/图示（少用）

**反 AIGC 层（4 条）→ 刘澜通过 3-4 条**：
- ✓ 自我修正（**刘澜特征**："我刚才有口误" / "我说错了"）
- ✓ 双向对话（"你说 X，我想 Y"）
- ✓ 经典引用准确性（精确引用）
- ✗ 暴露不完美（弱）
- ✗ 中二（弱）

**整体级总分：22-26/30（B-A 级 - 学者派代表）**

## 8. 1 篇样本摘录（"高质量思考的地基——系统思考"）

> 今天我们做一个预告，预告我们下面要读哪一本书。
>
> 我们要读的这本书叫《系统之美》，这是一个同学建议的书。她建议之后，我想了一想，觉得有点意思。
>
> 如果我们读别的书，往往都属于锦上添花。但是这本书属于打地基的书。我这两个隐喻没有对上，一个是锦上添花，一个是打地基，所以改一下——如果我们读别的书，往往都是建墙啊、搭房梁啊，甚至于属于室内设计，摆个花盆、摆个沙发这样的书。但是系统思考是属于打地基的书。基础不牢，地动山摇。
>
> 我刚才有一个口误，把"系统之美"说成"系统思考"了。因为《系统之美》讲的就是系统思考。
>
> 系统思考有多重要呢？我给大家举一两个例子。这些例子你很可能听我说过。我把它串起来告诉你系统思考为什么重要。
>
> 系统思考最基本的一点就是说，我们看待一个事物要从三个层次来看待。哪三个层次呢？就是**要素、连接和目标**。这就是系统的三个层次：要素、连接和目标。这个有多重要呢？
>
> 比如说我经常讲的一个模型是管理者三大能力模型。如果我现在问你，管理者三大能力是什么？你说不出来，那你跟着我就白学了啊。即使你说得出来，也可能是白学了。但是首先要说得出来。
>
> 管理者三大能力，第一，技术能力；第二，人际能力；第三，概念能力。这是一个经典的模型，我经常拿它来举例子。
>
> 如果你会系统思考的话，我问你管理者三大能力是什么，你都不用知道这个模型，就能够回答：第一是要素方面的能力，第二是连接上的能力，第三是目标上的能力。
>
> 要素的能力就是技术能力；连接的能力就是人际能力；目标层面的能力就是概念能力。
>
> 作为一个管理者，你要具备三个层次的能力。第一个，你作为一个要素，得有要素所要具备的技术能力。第二个，你要能够跟其他的要素连接起来，你要能去把你管的那些要素也连接起来，这就是人际能力。第三个，你这些连接为什么服务的呢？为目标服务的。你要看清楚那个目标，这就是概念能力。
>
> 所以管理者三大能力，它的底层结构是什么呢？是系统思考，是系统思考的三个层次。
>
> ---
>
> 我跟 ChatGPT 说，《系统之美》其实我有些没读懂，比如说增量和存量的部分。它就给我讲增量和存量是怎么回事。然后说，你到底具体什么不懂，跟我讲，我再举个贴近你生活的例子给你讲清楚。我说你现在不用讲了啊，等我具体读的时候再来向你请教。
>
> 有 ChatGPT 跟我一起读书是个好事。我并没有说它懂得就一定比我多，它是一个综合性全面选手，确实很多时候可以给我启发——**我刚才说错了，它懂得一定是比我多的。**但是在个别的地方，我也可以挑战一下他。
>
> 比如说昨天，我把《意如万事》这本书的开头部分又改了一下，然后发给它看。它看了之后，说大方向是好的，然后提了几个意见。大概提了 5 个意见，有 3 个我都给它驳回去了。后来它承认，确实我驳回的是对的，我想到了它没有想到的地方。
>
> **ChatGPT 是我的老师，我在这儿也算是你们的老师，那我希望，能够教你们一些东西，有些时候你们也能够有理有据地把我给驳回去。**
>
> 读《系统之美》特别好的地方，就是它真正能够改变你的思考。读这本书，比读其他的书，比如我们读过的叙事疗法，都更管用。因为所有那些都是以系统思考为基础的。这本书是真正的底层模式。
