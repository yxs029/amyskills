# 营销模型文章撰写器

本技能指导基于菲利普·科特勒的《营销管理》（第16版），为微信公众号创建高质量的营销模型文章。

## 何时使用此技能

在以下情况使用此技能：
- 撰写关于《营销管理》中营销管理模型的文章
- 为微信公众号创建质量一致的内容
- 需要结合理论、案例研究和个人经历
- 希望遵循经过验证的五段式框架结构
- 创建一系列基于模型的文章

## 核心框架：五段式结构

每篇文章都遵循这个经过验证的结构：

1.  **核心问题 (WHY)** - 这个模型解决了什么根本问题？
2.  **营销应用 (HOW)** - 如何通过具体案例使用该模型
3.  **模型本质 (WHAT)** - 这个模型是什么以及它如何运作？
4.  **个人应用** - 如何在现实生活和工作中应用这个模型
5.  **总结与升华** - 用有影响力的结束语作结

## 关键原则

### 1. 统一的案例研究
- 在所有文章中使用“夜猫咖啡”作为一致的案例研究
- 目标受众：寻求深夜能量和情感支持的996工作者（加班族）
- 价值主张：“深夜能量补给 + 情感陪伴”
- 这种一致性帮助读者通过一个商业故事理解不同的模型

### 2. 表格驱动的呈现
- 使用表格清晰地呈现复杂信息
- 第二部分（案例研究）：使用表格展示每个模型元素如何应用于夜猫咖啡
- 第三部分（模型本质）：使用表格定义模型组件和关键问题
- 保持表格简洁：每个单元格最多2-3句话

### 3. 个人故事整合
- 故事基于《成长故事2.0，我的2025》中的真实经历
- 从软件测试工程师到内容创作者/个人品牌建设者的转型
- 展示模型如何应用于个人职业发展
- 包括具体细节：数字、时间线、人物、对话

### 4. 语言风格
- 使用第一人称叙事（“我”）
- 与读者建立对话式语气（“我们”、“你”）
- 用通俗易懂的语言解释专业概念
- 使用比喻和类比来阐明抽象思想
- 避免术语过载；解释每个技术术语

### 5. 结束语（金句）
- 保持在10-20个字
- 使用对比、比喻或修辞手法
- 应能激发思考并令人难忘
- 必须与文章的核心信息保持一致

## 写作流程

### 第一步：研究与准备
1. 阅读《营销管理》第16版中的相关章节
2. 收集模型定义、框架图和示例
3. 查看用户的个人经历材料
4. 确认夜猫咖啡如何应用于此特定模型

### 第二步：大纲设计
1. 规划五段式框架
2. 为每个部分确定2-3个关键信息点
3. 规划表格位置和内容
4. 确定个人故事的切入点

### 第三步：草稿撰写
1. 从第二部分（案例研究）开始 - 最具体
2. 撰写第三部分（模型本质） - 确保准确性
3. 撰写第一部分（核心问题） - 引出模型
4. 撰写第四部分（个人应用） - 整合故事
5. 撰写第五部分（总结） - 构思结束语

### 第四步：修订与优化
- 检查逻辑流程：问题 → 应用 → 理论 → 实践 → 升华
- 验证表格的清晰度和完整性
- 确保语言易于理解，不过于专业化
- 确认个人故事感觉自然，不生硬
- 检查Markdown格式

### 第五步：最终审查
- 标题吸引人并包含模型名称
- 所有5个部分都存在且内容充实
- 表格清晰，信息完整
- 个人故事有支撑细节
- 结束语有影响力
- 没有拼写错误或格式问题

## 常见模型陷阱及避免方法

| 陷阱 | ❌ 错误 | ✅ 正确 |
|:---|:---|:---|
| **模型理解** | 混淆相似模型（如7P与7T） | 撰写前彻底理解模型定义；优先使用用户提供的材料 |
| **案例研究** | 过于模糊或笼统；模型应用不清晰 | 具体的产品名称、数字、时间线、人物；与模型元素的清晰联系 |
| **个人故事** | 生硬地嫁接到模型上；感觉牵强 | 自然整合；故事展示模型应用；包含具体细节 |
| **表格设计** | 信息过多；外观杂乱 | 内容简洁；每个单元格最多2-3句话；使用**粗体**标示关键术语 |
| **语言** | 过度专业化；与读者疏远 | 通俗易懂的解释；对话式语气；用比喻解释抽象概念 |
| **结束语** | 过长；过于复杂；难以记住 | 10-20个字；令人难忘；激发思考 |
| **用户体验** | 未使用或整合不佳的用户材料 | 深度整合真实经历；从提供的材料中提取具体细节 |
