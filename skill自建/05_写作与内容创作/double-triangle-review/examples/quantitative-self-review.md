## 最大瓶颈 + 突破路径

**最大瓶颈:体系 S2 TopN聚焦(3.1 分)**

S2 的核心是"主动放弃次要,聚焦核心主题"。当前我的状态:
- 同时在跑 5-6 个项目(arxiv skill、双三角 skill、Get笔记整合、调研 skill、个人写作)
- 没能主动砍掉次要
- 没有"30 天内只跑 3 个 TopN"的纪律

**30 天突破计划**:
1. **第 1 周**:列出当前所有项目,做"MECE 拆分 + ROI 排序"
2. **第 2 周**:砍掉 2 个最低 ROI 的项目(候选:调研 skill / 写作 habit tracker)
3. **第 3-4 周**:只跑 3 个 TopN(arxiv skill 优化 / 双三角 skill 完善 / 个人写作),各跑完一轮完整复盘

**成功标准**:30 天后 S2 复评 >= 3.5。
