## 6 要素 × 3 段位(定性)

### 1️⃣ 创造力(创新 / 提假设 / 大胆想象)

**自问**:有没有提出新解法?假设够不够大胆?有没有高水平的设想?

#### 基础
- **解放思想**:大胆提出创造性假设
- **分层自洽**:上下分层可推理,左右自洽可辩证
- **敢于想象**:有自己的独特想象力和设想
- 敢说、敢想,但多是组合现有元素

#### 进阶
- **第一性原理**:遵循本质和底层原理做事
- **分层自洽**:追求下层规律和上层规则统一
- **辩证思维**:找到规律的矛盾性,寻找更统一的更好规律
- 能从第一性原理出发,提出"为什么"问题,而不是"怎么拼"

#### 高阶
- **大胆设想**:不设限,大胆解放思想,找到足够多/大的想法
- **底层自洽**:理性评估,找到规律的底层合理性
- **假设试错**:构建实验试错体系,现实中不断验证
- **模型重构**:变成新的模型和范式,稳定复现创新

**对应量化子模块**:I1-I6
**段位映射**:I1 主动模仿 → I2 方案 → I3 商业 → I4 产品 → I5 技术应用 → I6 技术自研

### 2️⃣ 审美(品味 / 见识 / 判断力)

**自问**:对结果质量有没有高水平判断?粗打分能给多少?有没有校准机制?

#### 基础
- **有感觉**:对于好坏优劣有基本的分辨
- **有案例**:最佳实践清单和理解
- **粗打分**:20 分很差,40 分不够,60 分可用,80 分优秀,99 分无懈可击

#### 进阶
- **有定量**:综合加权打分机制
- **有维度**:建立雷达图评估角度
- **正负表**:有 to-do list 和 not-to-do list
- **校准法**:能通过样稿校准、版本对比、真实反馈,让 AI 逐步接近标准

#### 高阶
- **有超越**:基于最佳实践再次突破
- **有引领**:引领更多人的 Top 审美
- **有迁移**:跨大领域进行审美借鉴和高水平迁移

**对应量化子模块**:A1-A4
**段位映射**:A1 主动模仿 → A2 我能看见 → A3 筛选入围 → A4 提炼模型

---

### 3️⃣ 体系(框架 / 工作流 / 思维模型)

**自问**:过程是否稳定可复现?有没有 MECE / N 步法 / runbook?

#### 基础
- **明确的定义**:对于复杂概念有基本统一的定义
- **工作流**:解决某类问题的固定流程/方法
- **清单**:解决某一类问题的清单/禁止清单

#### 进阶
- **完备 MECE**:追求逻辑完备,不重不漏
- **科学工作流**:稳定高效的做事流程和里程碑
- **矩阵图**:按空间二维拆解复杂逻辑
- **N 步法**:按实践拆解成逻辑完备的里程碑结构
- **武器库**:熟练掌握建立各种类型的模型

#### 高阶
- **稀缺工作流**:自己建立 KnowHow 级别工作流
- **稀缺方法论**:构建一整套"本质-方法-技巧-案例"行业稀缺的方法体系
- **自己抽象有竞争力的体系**

**对应量化子模块**:S1-S4(人三角)
**段位映射**:S1 散点管理 → S2 TopN聚焦 → S3 MECE结构 → S4 逻辑链系统

### 4️⃣ AI 基本功(工具使用 / 技术 / 实操)

**自问**:工具选择是否合理?有没有封装成自有工作流?是否敢于尝试新工具?

#### 基础
- **既不迷信**:任何工具都有局限性
- **也不排斥**:任何工具都值得尝试
- **提示词工程**:撰写复杂专业的结构化框架 Prompt
- **刻意练习**:专家是刻意练出来的

#### 进阶
- **封装提示词**:系统提示词、YAl-partner
- **封装自动化**:工作流、智能体、Skill、OpenClaw
- **多工具创造**:多模态、VibeCoding

#### 高阶
- **有算法**:看底层算法/模型论文
- **有协同**:AI 和人类组织分工和协同
- **自进化**:构建自动进化体系/循环
- **武器库**:打造自己的 AI 分层武器库

**对应量化子模块**:K1-K5
**段位映射**:K1 认知入门 → K2 提示工程 → K3 智能体与RAG → K4 编程融合 → K5 体系化思维

### 5️⃣ AI 数据(资产 / 飞轮 / 复利)

**自问**:高质量数据有没有沉淀?有没有数据敏感度?有没有反馈闭环?

#### 基础
- **数据敏感**:对于业务数据有敏感性
- **正面案例 / 负面案例**

#### 进阶
- **形式**:非结构化 + 结构化数据
- **维度**:结果数据 + 过程数据 + 错误数据

#### 高阶
- **预判 / 识别 / 收集 / 处理 / 使用 / 反馈**:完整数据飞轮闭环

**对应量化子模块**:D1-D4
**段位映射**:D1 质量意识 → D2 整理能力 → D3 资产就绪 → D4 飞轮增值

### 6️⃣ AI 场景(机会 / 价值 / ROI)

**自问**:场景边界是否清晰?ROI 是否合理?有没有持续发现新场景的能力?

#### 基础
- **需求捕捉**:寻找痛痛的/叹气的/不得不做的关键场景
- **大胆假设**:AI 在这个场景下发挥足够大的价值
- **STAR 模型**:个人和组织,下限和上限

#### 进阶
- **AI 匹配**:AI 优势特性和场景特性匹配
- **评估 ROI**:考虑 3-5 个维度,多场景对比
- **定义边界**:善于剥离场景的内核和边界

#### 高阶
- **创新场景**:找到未被同行发现的高价值 AI 场景
- **持续发现**:有源源不断的场景探索和发现能力

**对应量化子模块**:S1-S4(AI 三角,Scene-STAR)
**段位映射**:S1 Seek → S2 Transform → S3 Accelerate → S4 Realize

## 复盘执行纪律

1. **段位不要客气**:某项是基础就是基础,别因为气氛好就给所有人都打进阶
2. **用 0-100 粗打分**:每个要素都打分,差距一目了然
3. **提升建议必须 1 小时内可开始**:否则是空话
4. **6 要素有相互影响**:数据飞轮 → 校准审美 → 提升体系;场景 → 倒逼创造力
5. **每次只挑 2-3 个最痛的下手**:不要"全面提升"

## 复盘的反模式

- ❌ "做得很好,继续加油" — 没有信息量
- ❌ "我们下次要注意 X" — 没量化,不可执行
- ❌ 跳过基础直接谈高阶 — 基础没打好,高阶是空中楼阁
- ❌ 只复盘失败不复盘成功 — 成功经验也是可迁移资产
- ❌ 复盘完不沉淀 — 不写到文档里就等于没做

## 复盘的高阶用法

- **跨项目对照**:拿这个项目的复盘和上个项目对比,看"我们的段位进步曲线"
- **跨人对照**:把团队每个人的复盘拼起来,看短板在谁
- **复盘自己**:对自己 6 个月前的项目做复盘,看审美有没有涨
