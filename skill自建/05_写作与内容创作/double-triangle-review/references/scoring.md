# 段位判定 + 报告输出规则

## 段位判定算法

```
对每个维度 dim:
  子模块按 order 升序排列
  从 order=1 开始扫描
  累计"已通过"的最长前缀
  段位 = 最后一个"已通过"的子模块名
  若 order=1 都未通过: 段位 = "未建立"
  若全部通过: 段位 = "已贯通"
```

### 段位 vs 子模块的关系

| 段位 | 含义 |
|---|---|
| **未建立** | order=1 的子模块都 < 3.5,基础未建 |
| **A1** | A1 >= 3.5,A2 < 3.5 |
| **A2** | A1+A2 >= 3.5,A3 < 3.5 |
| **A3** | A1+A2+A3 >= 3.5,A4 < 3.5 |
| **A4** | A1+A2+A3+A4 >= 3.5 |
| **已贯通** | 该维度所有子模块都 >= 3.5 |

### 6 维度 × 27 子模块段位速览

```
审美:  [A1 主动模仿] → [A2 我能看见] → [A3 筛选入围] → [A4 提炼模型]
体系(人): [S1 散点管理] → [S2 TopN聚焦] → [S3 MECE结构] → [S4 逻辑链系统]
创新:  [I1 流程创新] → [I2 方案创新] → [I3 商业创新] → [I4 产品创新] → [I5 技术应用] → [I6 技术自研]
场景:  [S1 探索定位 Seek] → [S2 变革视野 Transform] → [S3 效率加速 Accelerate] → [S4 价值落地 Realize]
基本功:[K1 AI认知入门] → [K2 提示工程核心] → [K3 智能体与RAG] → [K4 编程融合进阶] → [K5 体系化思维]
数据:  [D1 数据质量意识] → [D2 数据整理能力] → [D3 数据资产就绪] → [D4 数据飞轮增值]
```

## 雷达图绘制规则

6 个维度各画一条轴,每条轴 = 该维度均分(范围 1-5)。

- 1.0-3.4:橙红(未通过)
- 3.5-4.4:绿(通过)
- 4.5+:深绿(领先)

**面积感**:视觉上越饱满,综合能力越强。但**单维度突出比全面平庸更有价值**。

## 报告输出格式

完整报告应包含以下 8 个 section:

### 1. 一句话回顾
一段话,说清楚复盘对象、主体、时间跨度、整体结论。

### 2. 综合评分卡
```
综合分: 3.6 / 5.0
段位分布:
  - 审美:    A3 (3.8)
  - 体系:    S2 (3.2)
  - 创新:    I2 (3.5)
  - 场景:    S1 (3.6)
  - 基本功:  K3 (4.0)
  - 数据:    D2 (3.4)
最大瓶颈: 体系 (S2 未通过 S3,差 0.3)
最强维度: 基本功 (K3 已通过)
```

### 3. 维度雷达图(ASCII 或 Mermaid)
```
      审美
       3.8
      /    \
   3.4      3.2
  数据 ─── 体系
   3.4      3.2
      \    /
       3.6  3.5
      场景 ─ 创新
       3.6  3.5
        (基本功 K3)
```
(可选 ASCII 或输出 PNG)

### 4. 子模块详细分
表格列出每个子模块分数、通过状态(✓/✗)、变化趋势(对比上次)。

### 5. 最大瓶颈识别 + 突破建议
算法:找出 **order 最小且未通过** 的子模块,即"下一步该攻的"。

```
最大瓶颈: 体系 S2 TopN聚焦(2.8 分)
建议: 先稳定 S1(已 4.2),再攻 S2。S2 的核心是"主动放弃次要",
      建议下一步 30 天内:
        □ 列出所有当前研究主题
        □ 砍掉 30% 不重要的
        □ 留下 3 个 TopN,各跑 30 天
```

### 6. 第二瓶颈(辅助)
如果最大瓶颈 + 第二瓶颈能形成"双驱动",会更快突破。

### 7. 段位提升建议(每个维度 1 条)
- 审美:从 A3 → A4,核心是"开始画图谱、提炼模型"
- 体系:从 S2 → S3,核心是"先 MECE 拆一个完整项目"
- 创新:从 I2 → I3,核心是"做第一个多用户方案"
- ...

### 8. 复评时间 + 复评重点
下次复评建议在 **30-90 天**后。重点关注本次"最大瓶颈"是否突破。

## 与"老式"双三角清单体的区别

| 维度 | 老式清单体 | 量化版(本 skill) |
|---|---|---|
| 段位 | 基础/进阶/高阶(3 段) | 27 个子模块 + 通过/未通过(连续段位) |
| 评分 | 无 / 主观打 60/80/99 | 108 道题 × 1-5 分,平均+阈值 |
| 量化 | 无 | 雷达图 + 维度均分 + 趋势对比 |
| 可比性 | 不同人复盘不可比 | 同模型测评,结果可比 |
| 演进追踪 | 难 | 30-90 天复评,看涨/跌 |

**核心差异**:从"主观感知的 3 段"升级到"客观题测的 27 子模块连续段位"。

## 复盘执行纪律

1. **诚实打分**:不灌水、不压分
2. **第一反应**:不要反复纠结
3. **看行为不看意图**:问"做过吗"不是"想做吗"
4. **可执行建议**:每个建议都能 1 小时内开始
5. **下次复评**:必须设一个时间点,不能"以后再说"

---

## 极简模式(快速复盘,5 分钟)

如果时间不够做完整 108 题,可以做**快速版**:

只回答 6 个维度各 1 个问题:

1. **审美**:你最近收藏 / 标注过 3 篇以上"值得反复研究"的内容吗?(1-5)
2. **体系**:你的知识 / 项目有"统一入口 + 定期整理"吗?(1-5)
3. **创新**:过去 30 天你有没有**自创**(不是学别人的)一个方法 / 模型 / 工具?(1-5)
4. **场景**:你用 AI 解决了**真实业务痛点**而不是"测试玩玩"吗?(1-5)
5. **基本功**:你能写出 5 个自己常用的 prompt 模板吗?(1-5)
6. **数据**:你的数据有"统一标签 + 双向链接"吗?(1-5)

每个 1-5 分,粗打一遍,5 分钟完成,**只能做粗筛,不能替代完整测评**。

> 完整测评仍然推荐每 90 天做一次。

## 阈值参考表

| 子模块分 | 含义 | 行动建议 |
|---|---|---|
| **5.0** | 行业头部,可开课 | 找徒弟 / 出书 / 公开布道 |
| **4.5-4.9** | 稳定熟练 + 偶有创新 | 教别人,内部分享 |
| **4.0-4.4** | 稳定执行 | 自己做就行,偶尔分享 |
| **3.5-3.9** | 基本能用,但不稳 | 写 SOP / 固化流程 |
| **3.0-3.4** | 想做但做不到位 | 找出 1-2 个卡点,刻意练习 |
| **2.5-2.9** | 知道要做但常忘 | 加到 daily checklist |
| **2.0-2.4** | 偶有涉及 | 找师傅 / 找教程 |
| **< 2.0** | 完全未建立 | 先学基础,不要急着"应用" |
