# 子模块定义(27 个,完整)

本 skill 的评分粒度是**子模块(sub-module)**,而不是笼统的"基础 / 进阶 / 高阶"。
每个子模块都是 1 个可独立评估的能力单元,通过分数线 **3.5/5.0**。

子模块按**两个三角**组织,共 **6 大维度 / 27 子模块**:

---

## 三角一:人的能力(14 子模块)

### 1. 审美 Aesthetic(4 个)

| ID | 名称 | 描述 |
|---|---|---|
| A1 | 主动模仿 | 主动收藏、研究、模仿优质内容 |
| A2 | 我能看见 | 快速判断内容质量,识别逻辑漏洞 |
| A3 | 筛选入围 | 有明确主题,有选书标准,主动舍弃 |
| A4 | 提炼模型 | 总结规律,绘制图谱,提炼核心模型 |

### 2. 体系 System(4 个)

| ID | 名称 | 描述 |
|---|---|---|
| S1 | 散点管理 | 统一入口,定期整理,告别分散 |
| S2 | TopN 聚焦 | 聚焦核心主题,主动放弃次要 |
| S3 | MECE 结构 | 系统分类,搭建框架,不重不漏 |
| S4 | 逻辑链系统 | 因果链分析,系统方案,行动转化 |

> **注意**:S1-S4 在两个三角里都出现,**人三角的 S 偏知识管理**,**AI 三角的 S 偏场景定位**。评估时需要区分。

### 3. 创新 Innovation(6 个)

| ID | 名称 | 描述 |
|---|---|---|
| I1 | 流程创新 | 固定的输入-处理-输出工作流 |
| I2 | 方案创新 | 多方案思维,尝试新方法,持续改进 |
| I3 | 商业创新 | 知识服务多用户,探索新渠道新形态 |
| I4 | 产品创新 | 书变课程,课程变社群,知识变训练营 |
| I5 | 技术应用 | AI 辅助学习写作,自动化工具提效 |

## 三角二:AI 的能力(13 子模块)

### 4. 场景 Scene-STAR(4 个)

> STAR = Seek/Transform/Accelerate/Realize

| ID | 名称 | 描述 |
|---|---|---|
| S1 | 探索定位 Seek | 明确用 AI 搭建知识体系的目的与主轴领域,避免盲目跟风 |
| S2 | 变革视野 Transform | 知识体系的终局预判与长期路径规划,与个人事业/创作关联 |
| S3 | 效率加速 Accelerate | 用 AI 攻克采集/整理/检索/输出等具体瓶颈,量化时间收益 |
| S4 | 价值落地 Realize | 知识库从个人消化走向对外交付,复用与 ROI 清晰 |

| ID | 名称 | 描述 |
|---|---|---|

| K3 | 智能体与 RAG | 用智能体/RAG 搭建自动化知识工作流,端到端串联知识流 |

| K5 | 体系化思维 | 用 PARA/MOC 等方法论指导 AI 知识库设计,全链路 SOP 与多轮迭代 |

### 6. 数据 Data(4 个)

| ID | 名称 | 描述 |
|---|---|---|

## 子模块之间的依赖关系(进阶用)

虽然每个子模块独立评估,但实际能力有递进关系:

```
A1 主动模仿  ─→  A2 我能看见  ─→  A3 筛选入围  ─→  A4 提炼模型
   (输入)        (判断)         (取舍)         (抽象)

S1 散点管理  ─→  S2 TopN聚焦  ─→  S3 MECE结构  ─→  S4 逻辑链系统
   (收纳)        (取舍)         (分类)         (推理)

I1 流程创新  ─→  I2 方案创新  ─→  I3 商业创新  ─→  I4 产品创新
                                    ↓
                                 I5 技术应用  ─→  I6 技术自研
```

**段位跳跃建议**:先稳定前一子模块(>= 4.0),再攻下一个,不要跳跃。
