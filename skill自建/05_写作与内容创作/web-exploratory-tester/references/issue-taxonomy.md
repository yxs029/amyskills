# Issue 分类与严重性分级（dogfood 标准）

## 严重性 4 级

### 🔴 Critical（致命）
核心功能完全不可用，或导致数据丢失、安全漏洞。

**典型例子：**
- 应用崩溃或白屏
- 表单提交静默丢失用户数据
- 登录完全不可用（最核心流程断）
- 支付流程失败却已扣款
- XSS / 凭证泄露 / 鉴权绕过等安全漏洞
- 空 dialog / 空错误页让用户卡死

### 🟠 High（高危）
功能严重受损但可能有 workaround。

**典型例子：**
- 关键按钮点击无反应
- 搜索对合法查询返回空
- 表单校验拒绝合法输入
- 页面加载但关键内容缺失或乱码
- 导航链接指向 404 或错误页面
- 核心页面的 uncaught JavaScript 异常

### 🟡 Medium（中危）
影响体验但不阻塞核心功能。

**典型例子：**
- 布局错位/重叠
- 图片加载失败
- 性能慢（>3 秒加载延迟）
- 表单字段缺少校验反馈
- 类似的页面风格不统一
- 暴露的内部信息（应隐藏但不影响功能）

### 🔵 Low（轻微）
不影响功能的细节问题。

**典型例子：**
- 错别字/语法错误
- 微小间距/对齐不一致
- 生产环境留 placeholder 文案
- favicon 缺失
- 生产环境的 console.log
- 不达 WCAG AA 但不失败的对比度

## 分类 6 类

| 分类 | 含义 | 例子 |
|---|---|---|
| **Functional** | 功能不按预期工作 | 按钮无响应、表单不提交、流程断、数据显示错误 |
| **Visual** | 视觉呈现问题 | 布局错位、图片破损、样式不一致、响应式失败、z-index 错误 |
| **Accessibility** | 阻碍残障用户使用 | 缺 alt text、对比度差、键盘不可达、缺 ARIA、焦点不清 |
| **Console** | JS 控制台错误 | 未捕获异常、4xx/5xx、CORS 警告、混内容警告 |
| **UX** | 功能可用但体验差 | 导航混乱、缺 loading、缺反馈、交互不一致、错误消息无用 |
| **Content** | 文案/媒体问题 | 错别字、占位符、过期信息、空段落、死链、误导标签 |

## 复现步骤标准格式

每个 issue 必须包含：

```
**Steps to Reproduce:**
1. 访问 <URL>
2. 点击 <element>
3. 输入 <value>
4. 观察结果

**Expected Behavior:** <应该发生什么>
**Actual Behavior:** <实际发生什么>
**Screenshot:** MEDIA:./screenshots/NN-issue.png
```

## 排序规则

报告中的 issue 顺序：
1. **严重性优先**：Critical > High > Medium > Low
2. **同严重性内按 URL 路径深度**：浅路径在前
3. **同页面内的 issue 按用户操作流程**：先发现的在前
