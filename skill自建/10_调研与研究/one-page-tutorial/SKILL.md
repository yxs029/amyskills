## 工程护栏（better-skill 补丁 · 2026-11-11）

### 初始对话协议（必修 P0-3）
多步任务的第一步必须停顿确认：「我计划分 X 步，预期产出 Y，是否开始？」；得到明确确认前不得进入执行。

### 触发时机（必修 P0-1）
当用户提出本技能覆盖的任务、或明确点名本技能时使用；同一意图的不同说法（改述）也应能触发。

### 分阶段退出条件（必修 P1-5）
每个阶段须有明确完成标志：产出物齐全、自检通过、无未决阻塞，方可进入下一阶段。


# 一页纸教程生成技能（V2.0 融合升级版）

## 工作流总览

生成一页纸教程分为四个阶段，按顺序严格执行：

1. **深度调研阶段**：多维度全网搜索，收集权威信息与高阶实战案例
2. **知识提炼阶段**：按 V2.0 融合认知模型框架萃取核心知识
3. **输出排版阶段**：按标准模板生成符合「清单体视觉规范」的 Markdown 教程
4. **质量自检阶段**：对照《一页纸教程质量 Checklist》进行打分，低于 90 分必须重写

---

## 阶段一：深度调研策略

### 搜索维度矩阵

针对用户话题，依次执行以下维度的搜索，每个维度至少发起 1 次搜索并访问 2 个以上来源 URL：

| 维度        | 搜索意图                 | 示例查询模式              |
| --------- | -------------------- | ------------------- |
| **定义与本质** | 是什么、核心概念、底层逻辑        | `{话题} 是什么 定义 本质`    |
| **层级与分类** | 宏观/中观/微观拆解、同类对比      | `{话题} 结构 分类 区别`     |
| **步骤与场景** | 怎么做、实操流程、真实业务场景      | `{话题} 教程 步骤 案例`     |
| **高阶实战**  | L5/L6 级别应用、跨界重构、专家洞察 | `{话题} 最佳实践 进阶应用 专家` |
| **边界与误区** | 适用条件、失效临界点、常见错误      | `{话题} 局限性 缺点 误区`    |
| **进阶资源**  | 延伸阅读、工具、社区           | `{话题} 推荐资源 权威指南`    |

### 调研质量要求

- 优先访问官方文档、学术论文、权威博客（避免仅依赖搜索摘要）
- 中英文各搜索至少一次，以获取更广泛视角
- 必须找到至少一个**高阶实战案例**（展示该概念在极高熟练度下的终极应用形态）
- 必须找到该概念的**失效临界点**（绝对不能用于什么场景）

## 阶段二：知识提炼框架（V2.0 融合版）

调研完成后，按以下「WHAT-WHY-HOW-WHEN-WATCH OUT」五层认知模型组织信息，并强制嵌入子框架：

| 层级 | 认知问题 | 核心要求与子框架嵌入 |
|------|----------|----------|
| **引言** | 这是什么？ | 1 句严谨定义 + 1 句「大白话版」辅助理解 |
| **WHAT** | 本质是什么？ | 1. **反差与本质**：打破常识误区，直击底层逻辑<br>2. **层级拆解**：按宏观/中观/微观结构化呈现<br>3. **谱系定位与共识**：横向对比同类概念，并提炼 1-3 条底层共识 |
| **WHY** | 为什么重要？ | 核心痛点解决与具体价值主张（需数据或理论支撑） |
| **HOW** | 怎么做？ | 1. **价值对比**：Before-After 状态差异<br>2. **场景化步骤**：3-5 步，每步必配真实场景<br>3. **高阶案例**：展示 L5/L6 级别跨界实战<br>4. **执行闭环**：复盘修正机制与底层原则 |
| **WHEN** | 何时/何处用？ | **精细化边界定义**：精确界定生效条件 vs. 失效临界点 |
| **WATCH OUT** | 要注意什么？ | 2-4 条最高频误区及正确做法纠正 |

## 阶段三：输出排版规范（清单体视觉）

严格使用 `references/output-template.md` 中的模板结构，并遵守以下视觉纪律：

- **拒绝大段落**：任何超过 3 行的纯文本段落，必须拆解为带项目符号（-）的列表。
- **表格优先**：凡是涉及对比、分类、层级的内容，强制使用 Markdown 表格呈现。
- **逻辑单元**：列表的每一项必须是一个完整的主谓宾逻辑单元，尽量不折行。
- **视觉重点**：高频且准确地使用加粗（**）来标注关键概念和核心动作。
- **禁止修辞**：不得使用 emoji、过度修辞、模糊表述（如「非常重要」「值得注意」）。

## 阶段四：质量自检（Checklist 90分基准线）

在输出最终 Markdown 文件前，AI 必须在内部（或通过 thought 过程）对照以下 5 大维度、20 个检查项进行自检。**每个检查项 5 分，总分低于 90 分必须返回阶段二重写。**

### 结构完整度（20分）
1. [ ] 双轨定义：包含严谨版和大白话版
2. [ ] 模块齐备：WHAT/WHY/HOW/WHEN/WATCH OUT 完整
3. [ ] 资源延伸：提供高质量参考链接
4. [ ] 信息溯源：标明生成时间与来源

### 认知友好度（20分）
5. [ ] 反差引入：指出常识误区，直击本质
6. [ ] 层级拆解：概念按宏观/中观/微观拆解
7. [ ] 谱系定位：通过表格明确同类知识体系位置
8. [ ] 共识提炼：罗列分类后提炼 1-3 条底层共识

### 理论严谨度（20分）
9. [ ] 理论深度：触及底层逻辑（认知科学/经济学等）
10. [ ] 边界精细：精确界定生效条件与失效临界点
11. [ ] 跨界印证：引入跨学科类比拓宽解释力
12. [ ] 事实支撑：关键论断有数据/调研/经典理论支撑

### 实践指导性（20分）
13. [ ] 价值对比：展示 Before-After 状态差异
14. [ ] 场景化步骤：每个执行步骤紧跟真实业务/生活场景
15. [ ] 高阶案例：引入贯穿始终的 L5/L6 级别实战案例
16. [ ] 执行闭环：提供复盘修正机制

### AI机读性与视觉规范（20分）
17. [ ] 拒绝大段落：超过 3 行纯文本已拆解为列表
18. [ ] 表格优先：对比/分类/层级内容已使用表格
19. [ ] 逻辑单元：列表项为主谓宾完整单元，不折行
20. [ ] 视觉重点：高频准确使用加粗标注关键概念
