# PromptXray PRD v1.0 要点

> 从 2026-06-11 Siri 解析项目中提炼的产品方向，细节见 `~/文档/siri_system_prompts_分析报告/Siri系统提示词/PromptXray_PRD_v1.0.pdf`

## 产品定位

丢进去一份 AI 系统提示词语料库，吐出来一份结构化解析报告。

## 双轨模式

| 轨道 | 定位 | 语料来源 | 收费 |
|---|---|---|---|
| A | 企业"提示词体检" | 客户上传自有提示词 | SaaS 订阅 |
| B | 行业分析平台 | 公开/泄露的头部 AI 提示词 | 免费示范→深度付费 |

## 核心方法论：5 步拆解法

PromptXray 的技术壁垒不在 AI 本身，而在**拆解流程的方法论**。这套方法论从实际项目中验证出来，确保任何语料库都能系统性地拆干净。

### Step 1：解包（Unpack）

自动识别输入格式（RAR/ZIP/文件夹/文本），解压，统计文件数和总大小。

### Step 2：画像（Scan）

遍历每个文件，记录 5 项元数据（字节数/行数/头5行/尾5行/关键词），生成全量画像 JSON。

**★ 关键子步骤：合并文件切分**

语料库经常有多条提示词拼在一个文件里的情况（如 GitHub Gist 导出）。识别特征：
- 文件体积异常大（>50KB）但只有 1 个文件
- 文件内出现重复的分隔符（Unicode 长横线 `──────` / `---` / `===` / `#` 标题）
- 文件内出现多条 "You are..." 开头

切分算法：按分隔符正则切分，过滤 <50 字符的碎片，标记 `is_real_sp: true`。

统计公式：`总提示词数 = 原始文件数 + 切分出的额外条数 - 被切分的文件本身`

### Step 3：分类（Classify）

每条 SP 打 5 个标签：来源状态（新增/旧版）、嵌入方式（编译/独立文件）、所属框架、功能域（可跨域）、一句话描述。

分类用 3 轮递进：
1. **关键词粗分**：按预设关键词表自动打标
2. **框架校准**：有框架名的以框架为准（编译级来源更可靠）
3. **人工审校**：>1KB 文件或矛盾条目人工确认

输出 `file_catalog.json`（结构化索引）+ `domain_stats.json`（域统计）。

### Step 4：精读（Deep Read）

LLM 逐段解读核心文件，提取 5 层结构：

| 层 | 名称 | 回答什么问题 |
|---|---|---|
| L1 | 人格（Identity） | AI 怎么定义自己？ |
| L2 | 原则（Principles） | 铁律和红线是什么？ |
| L3 | 资产（Assets） | 有多少条提示词？怎么分的？ |
| L4 | 执行（Runtime） | 从接收到输出，怎么一步步跑的？ |
| L5 | 表现（Product） | 用户在不同场景下看到什么？ |

精读按文件优先级：总章程全文精读 → 各域核心文件分段精读 → 短文件批量扫描。

**跨文件关联**：标注 SP 之间的引用/被引用关系（如总调度引用子任务、安全护栏被所有域引用）。

### Step 5：输出（Deliver）

根据受众选报告模式：
- **技术版**：全量提示词清单（按域分组，每条配文件名/字节/版本/一句话）+ 结构化 JSON + HTML 仪表盘
- **大白话版**：零术语、配场景、口语化
- 默认两个都做（先技术版拿数据，再大白话版翻译）

### 方法论验证数据

从 Siri 项目的实际结果验证：
- 189 个原始文件 → 切分后 243 条提示词（gistfile1.txt 切出 55 条）
- 29 个功能域，最大域 96 条，最小域 1 条
- 22.6% 的 SP 跨域，说明提示词设计高度复用
- 全量清单 742 行，每条可追溯到原始文件
- 大白话版 49 页 PDF，技术版 46 页 PDF

## 竞品空白确认

- system_prompts_leaks（4万Star）：只收集，不拆解
- PromptPerfect / PromptPilot：只优化/写，不拆解
- PromptGuard：只安全防护，不结构分析
- **结论**：提示词拆解分析赛道无人做

## MVP 路线

- Phase 1（2周）：Python CLI，`promptxray analyze ./my-prompts/ --audience developer --output report.pdf`
- Phase 2（4周）：Web 平台 + 5 份示范报告
- Phase 3（8周）：商业化（用户系统 + API + 企业私有部署）

## 商业模式

- 免费版：5 份示范 + 每月 3 次
- 专业版：¥99/月，无限解析 + 安全审计
- 企业版：¥999/月，API + 私有部署

## 法律边界

- B 轨拆解他人提示词有灰区 → 声明"技术研究" + 不提供原始下载 + 只输出分析报告
- A 轨客户自有提示词 → 无风险，数据处理协议
