# AI趋势报告排版

## 概述

本技能定义了 AI 趋势周报的标准 Markdown 排版格式，基于真实发布的报告文档提炼而成。使用时，复制 `templates/ai_trend_report_template.md` 作为起点，将占位符替换为实际内容即可。

## 整体结构

报告采用"总-分-总"框架，固定包含以下模块：

1. **开场白**：纯文本，介绍作者、系列背景、本期时间范围。
2. **#00 核心摘要**：按各层级（M/U/S/E）分别用加粗小标题 + 1-2句概括。
3. **#01 ~ #04 正文主体**：每个层级为一个模块，模块内含 2-3 个具体事件/趋势。
4. **#05 总结**：1-2句收尾升华。
5. **结尾互动**：引导读者获取更多信息。

各模块之间使用 `---` 水平分割线隔开。

## Markdown 语法规范

### 标题层级

| 层级 | 语法 | 说明 |
| :--- | :--- | :--- |
| 模块标题（一级） | `### <font color="#ff0000">#01</font> 标题文字` | 三级标题；编号用 HTML `<font>` 标签染红色 `#ff0000` |
| 事件标题（二级） | `#### 1. 标题文字` | 四级标题；带阿拉伯数字编号 |
| 摘要小标题 | `**层名（缩写）**` | 加粗，无标题级别 |

### 文本强调

- 摘要中各层名称使用 `**加粗**`，独占一行，下方紧跟一行概括文字。
- 正文中的关键结论使用 `**加粗**` 内联强调，其余正文不加粗。

### 段落与间距

- **句号即换行（核心铁律）**：每行只写一句话，句号（`。`）后立即换行，绝不在同一行内连写两句。经统计，原文档中单句行占比高达 **88.7%**，是最严格执行的排版规则。
- 段落（行）之间空一行（即两个回车），形成视觉分组。
- 模块末尾（`---` 前）保留一个含两个空格的空行（`  `），增加视觉留白。
- **例外情形**：冒号引导句（`科特勒提出了一个解决方案：`）、引号内对话句、列举项等本身不以句号结尾的行，不受此规则约束。

### 分割线

- 每个主要模块（#00 ~ #05）之间统一使用 `---` 分割。

## 排版示例

```markdown
### <font color="#ff0000">#01</font> 奇迹层（Miracle）：AI的长期未来与社会变革

奇迹层关注AI长期的未来思考、科学幻想、职业变革及AGI的发展。

#### 1. AI对就业市场的重塑与杠铃策略

随着AI技术的快速普及，关于AI替代人类工作的讨论愈发激烈。

马斯克近期转发的AI失业名单指出，高数字化职业面临较高的替代风险。

专家指出，**AI会替代部分岗位，但不会替代人类整体就业，新岗位会以更大规模出现。**
```

## 注意事项

- 不使用一级标题（`#`）和二级标题（`##`），文章标题通常在文档外部（如公众号标题栏）处理。
- 模块编号从 `#00` 开始，总结固定为 `#05`（或根据模块数量顺延）。
- `<font color="#ff0000">` 仅用于模块编号，不用于正文。
- 保留用户给你的原始内容，不要修改任何内容
