# 四象限爆款标题迭代 Checklist

本 Checklist 旨在通过标准化的流程，帮助创作者在阅读文章内容后，精准定位目标用户象限，并基于对应的“四力配比”对标题进行量化打分与迭代优化。

---

## 步骤一：前置诊断 —— 读内容，定象限

在构思标题前，**必须先通读文章内容**，并回答以下三个问题，以确定文章服务于哪个象限的用户。

1.  **这篇文章的核心目的是什么？**
    *   [ ] A. 给出明确的解决方案，促使用户行动/购买（→ 推进决策）
    *   [ ] B. 表达理解与共情，让用户觉得“你懂我”（→ 建立偏好）
    *   [ ] C. 借势大众热点，输出独特价值观，吸引广泛关注（→ 扩大认知）
    *   [ ] D. 打破用户的固有认知，描绘一个向往的结果（→ 唤醒需求）
2.  **这篇文章主要写给谁看？**
    *   [ ] A. 带着明确问题来找答案的人（意向用户）
    *   [ ] B. 知道自己有痛点，但处于焦虑/犹豫中的人（意识用户）
    *   [ ] C. 漫无目的刷手机的吃瓜群众（大众用户）
    *   [ ] D. 还没意识到自己需要改变的人（潜在用户）
3.  **这篇文章交付的核心价值是什么？**
    *   [ ] A. 解题价值（干货/方法论）
    *   [ ] B. 情绪价值（抚慰/嘴替）
    *   [ ] C. 社交价值（谈资/站队）
    *   [ ] D. 认知价值（新知/视野）

**诊断结果判定：**
*   选 A 最多 ➔ **第一象限（右上）：痛点选题（意向用户）**
*   选 B 最多 ➔ **第二象限（左上）：情绪选题（意识用户）**
*   选 C 最多 ➔ **第三象限（左下）：热点选题（大众用户）**
*   选 D 最多 ➔ **第四象限（右下）：认知选题（潜在用户）**

---

## 步骤二：分象限打分与迭代 Checklist

根据步骤一的判定结果，选择对应的 Checklist 对初稿标题进行打分（每项 1-5 分，满分 25 分）。
*   **18-25分**：优秀，可直接发布。
*   **12-17分**：及格，需针对低分项进行微调。
*   **12分以下**：不及格，需推翻重写。

### 象限一（右上）：痛点选题 Checklist（意向用户）
**核心驱动力：承诺驱动（承诺力40% > 相关力35% > 钩子力15% > 好奇力10%）**
**核心目标：证明"我有药，且有效"**

| 评分维度 | 检验标准（1-5分） | 得分 | 迭代建议 |
| :--- | :--- | :---: | :--- |
| **1. 承诺力（核心）** | 是否直接亮出了明确的结果、效果或方法数量？（如：提升300%、3个方法） | | 如果没有，加上具体的数字或效果承诺，降低用户的决策成本。 |
| **2. 相关力（核心）** | 是否精准命中了用户的痛点场景或身份标签？（如：月薪5000、拖延症晚期） | | 如果太泛，加入更具体的场景词，让用户一眼识别“这是说我的问题”。 |
| **3. 钩子力（辅助）** | 是否有适度的词汇吸引注意力，但没有过度夸大？ | | 避免使用“震惊”、“绝对”等极端词，保持专业和克制。 |
| **4. 好奇力（克制）** | 是否避免了过度卖关子？（用户要的是答案，不是谜语） | | 如果标题像个谜语，直接把部分答案或结果写在标题里。 |
| **5. 真实性与呼吸感** | 标题是否与文章提供的解决方案完全一致？是否没有堆砌太多元素？ | | 删掉多余的修饰词，确保标题干净利落，不当标题党。 |
| **总分** | | **/25** | |

---

### 象限二（左上）：情绪选题 Checklist（意识用户）
**核心驱动力：共鸣驱动（相关力40% > 钩子力35% > 好奇力15% > 承诺力10%）**
**核心目标：证明"我懂你，是同类"**

| 评分维度 | 检验标准（1-5分） | 得分 | 迭代建议 |
| :--- | :--- | :---: | :--- |
| **1. 相关力（核心）** | 是否使用了强烈的身份标签或群体词建立“同类”连接？（如：东亚小孩、成年人） | | 强化身份认同，让用户觉得你是在对“他们这个群体”说话。 |
| **2. 钩子力（核心）** | 是否精准触发了某种情绪（委屈、愤怒、怕、疲惫），且情绪颗粒度足够细腻？ | | 将高唤醒词（崩溃/扎心）替换为深共鸣词（治愈/懂你/允许自己），降低情绪噪音。 |
| **3. 承诺力（克制）** | 是否弱化了功利的利益承诺，转而提供情绪抚慰或立场表达？ | | 删掉“教你赚钱/成功”的字眼，改为“抱抱你/我懂你的难”。 |
| **4. 好奇力（辅助）** | 是否留下了一点情感上的悬念或内心独白的空间？ | | 用半句话或省略号结尾，给读者自我代入的留白空间。 |
| **5. 真实性与呼吸感** | 情绪表达是否真诚不做作？是否避免了无病呻吟？ | | 读一遍标题，如果觉得“太矫情”，就换成更平实、自嘲的语气。 |
| **总分** | | **/25** | |

---

### 象限三（左下）：热点选题 Checklist（大众用户）
**核心驱动力：情绪借势（相关力40% × 钩子力30% × 好奇力20% × 承诺力10%）**
**核心目标：借势情绪，输出价值观，提供社交货币**

| 评分维度 | 检验标准（1-5分） | 得分 | 迭代建议 |
| :--- | :--- | :---: | :--- |
| **1. 相关力（核心）** | 是否洞察到了热点背后的“大众情绪缺口”，并与之挂钩？ | | 不要只做客观报道，要把热点事件与普通人的生活/情绪联系起来。 |
| **2. 社交货币（核心）** | **关键检验**：用户转发这个标题到朋友圈，会觉得“有面子”或“说出了心里话”吗？ | | 如果标题只是个资讯，加入你的独特态度或价值观站队，让它成为用户的“嘴替”。 |
| **3. 钩子力（辅助）** | 是否包含了热点关键词、人物或特定的情绪周期（如：周五下午、调休）？ | | 确保热点词或周期词在标题的前半部分，第一时间打断滚动。 |
| **4. 好奇力（辅助）** | 是否提供了一个反常识的视角或独特的切入点？ | | 避免人云亦云，用“大话题，小切口”制造认知反差。 |
| **5. 真实性与呼吸感** | 借势是否自然？是否避免了强行蹭热点引起的受众反感？ | | 确保文章内容真的能支撑起标题的价值观，不为了蹭而蹭。 |
| **总分** | | **/25** | |

---

### 象限四（右下）：认知选题 Checklist（潜在用户）
**核心驱动力：认知唤醒（好奇力35% × 承诺力30% × 相关力20% × 钩子力15%）**
**核心目标：打破旧知，场景/结果唤醒**

| 评分维度 | 检验标准（1-5分） | 得分 | 迭代建议 |
| :--- | :--- | :---: | :--- |
| **1. 好奇力（核心）** | 是否成功制造了“认知反差”或否定了某种常识？（如：越自律越穷） | | 找出大众普遍认同的观点，在标题中提出质疑或反转，激发求知欲。 |
| **2. 承诺力（核心）** | 是否描绘了一个用户向往的“美好结果”或“新认知红利”？ | | 纯粹的猎奇不够，必须告诉用户“知道这个新认知后，你能得到什么好处”。 |
| **3. 相关力（辅助）** | 是否将新认知与用户熟悉的“具体场景”进行了软链接？ | | 如果认知太抽象，加入一个具体的痛点场景，让用户产生代入感。 |
| **4. 钩子力（辅助）** | 是否使用了适度的颠覆性词汇（如：废掉、真相）来激活注意力？ | | 适度使用，但要确保文章内容能接得住这种颠覆感。 |
| **5. 真实性与呼吸感** | 认知颠覆是否有理有据？是否避免了故弄玄虚？ | | 确保标题提出的新认知在文章中有扎实的逻辑支撑，而不是诡辩。 |
| **总分** | | **/25** | |

## 步骤三：全局复核与 A/B 测试

在完成单象限的打分与迭代后，进行最后一步的全局复核：

1.  **象限跃迁思考**：这个标题是否可以微调四力配比，改写成另一个版本，发给不同象限的用户？（一鱼多吃）
2.  **A/B 测试准备**：如果条件允许，挑选得分最高的两个不同维度的标题（例如一个偏痛点承诺，一个偏情绪共鸣），进行小范围的 A/B 测试，用真实数据指导最终选择。
