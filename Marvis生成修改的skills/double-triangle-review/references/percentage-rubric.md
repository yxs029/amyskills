# 0-100% 段位量化标准(报告 1 用)

> 本文件把 1-5 分李克特量表换算成 **0-100% 百分比分**,用于报告 1 的段位判定 + 可视化。

## 换算规则

### 单题:1-5 分 → 0-20 分

每个子模块的题,从 1-5 分(李克特量表)换算成 0-20 分:

```
0-20 分 = (raw_score - 1) × 5
```

| 1-5 分 | 0-20 分 | 含义 |
|---|---|---|
| 1 | 0 | 完全不符合 |
| 2 | 5 | 基本不符合 |
| 3 | 10 | 中立 |
| 4 | 15 | 基本符合 |
| 5 | 20 | 完全符合 |

### 反向题:翻转后再换算

```
0-20 分 = (6 - raw_score - 1) × 5 = (5 - raw_score) × 5
```

| 1-5 分(反向) | 0-20 分 | 含义 |
|---|---|---|
| 1 | 20 | 完全不符合(说明我做得很好) |
| 2 | 15 | 基本不符合 |
| 3 | 10 | 中立 |
| 4 | 5 | 基本符合 |
| 5 | 0 | 完全符合(说明我做得差) |

### 子模块分:0-20 分

子模块分 = 子模块内所有题(0-20 分)的平均,保留 1 位小数。

### 维度总分 = 20 × 子模块数

| 维度 | 子模块数 | 满分数 |
|---|---|---|
| 审美 | 4 | 80 |
| 体系(人) | 4 | 80 |
| 创新 | 6 | 120 |
| 场景 | 4 | 80 |
| 基本功 | 5 | 100 |
| 数据 | 4 | 80 |
| **合计** | **27** | **540** |

### 综合分(0-100%) = (6 维度总分之和 / 540) × 100

或简化为:**综合分 = 27 子模块分总和 ÷ 540 × 100%**

---

## 段位判定(每个维度独立)

```
要素总分 = 该维度内所有子模块分之和(满分见上)
要素百分比 = 要素总分 / 要素满分 × 100%

段位 = 初阶(< 30%) | 进阶段(30%-60%) | 高阶(60%-100%)
```

### 段位含义速查

| 段位 | 百分比 | 特征描述 |
|---|---|---|
| **初阶** | < 30% | 知道要做,但还没开始 / 完全未建立 |
| **进阶段** | 30-60% | 已开始执行,但还没稳定,常忘 |
| **高阶** | 60-100% | 稳定执行,可输出 / 教学,跨场景可迁移 |

### 段位判定示例

审美总分 80 分:

| 实得分 | 百分比 | 段位 |
|---|---|---|
| 0-23 | < 30% | 初阶 |
| 24-47 | 30-60% | 进阶段 |
| 48-80 | 60-100% | 高阶 |

创新总分 120 分:

| 实得分 | 百分比 | 段位 |
|---|---|---|
| 0-35 | < 30% | 初阶 |
| 36-71 | 30-60% | 进阶段 |
| 72-120 | 60-100% | 高阶 |

---

## 综合分到段位

综合分(0-100%)也能直接映射段位:

| 综合分 | 段位 |
|---|---|
| < 30% | **初阶**(知道,未做) |
| 30-50% | **进阶段 A**(开始做,不稳) |
| 50-70% | **进阶段 B**(稳定执行,还未引领) |
| 70-100% | **高阶**(可输出 / 教学 / 迁移) |

> 注:综合段位仅供参考,**真正的段位应以维度最低分定**(短板原则)。一个人综合 70% 但体系 25%,实际段位仍然是"体系初阶"。

## 与早期 1-5 分版的对照

| 1-5 分版 | 0-100% 版 |
|---|---|
| 通过线 3.5 | 段位线 30% / 60% |
| 子模块段位 A1/A2/A3/A4 | 维度段位 初阶/进阶段/高阶 |
| 综合分 3.5/5.0 | 综合分 70% / 100% |
| 报告输出 markdown | 报告 1 + 雷达图 + 段位徽章 |

> **重要**:本 skill 默认两套并存 —— 1-5 分(题库测评用)+ 0-100%(报告可视化用)。可在 `scoring.md` 选其一,本文件只展示 0-100% 版用于报告。

## 自动评分时的注意事项

当 skill **调用 LLM 自动评分**(而非用户答 108 题)时,LLM 给出的是 0-20 分制的子模块分,直接套用上面的换算即可。

**LLM 输出格式**(详见 `scripts/eval_prompt.md`):

```json
{
  "A1": 15,
  "A2": 18,
  "A3": 10,
  "A4": 8,
  "S1_人": 14,
  "S2_人": 8,
  ...
  "D4": 5
}
```

LLM 给每个子模块 0-20 分,script 自动:
1. 按维度汇总
2. 算百分比
3. 判定段位
4. 生成报告 1 + 报告 2
