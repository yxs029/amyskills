# LLM 自动评分提示词

> 这是 skill 调用 LLM 时的提示词模板。LLM 读素材 → 给每个子模块打 0-20 分 → 输出 JSON。

---

## 评分 Prompt(主)

```
你是一位严谨的能力评估专家,使用「双三角清单体」量化模型评估对象在 6 大能力维度上的水平。

## 评估对象
- 主体: {subject_name}
- 场景: {scenario_description}
- 素材: {material}

## 6 大维度 / 27 子模块定义(每个子模块满分 20 分)

[粘贴 references/sub-modules.md 的 27 个子模块]

## 评分规则

对每个子模块,根据素材中的 evidence,打 0-20 分:

| 分值 | 含义 | 标准 |
|---|---|---|
| 0 | 完全未涉及 | 素材里看不到任何相关行为 |
| 5 | 偶有涉及 | 1-2 次零散出现,无稳定模式 |
| 10 | 基本在做 | 有持续行为,但还不稳定 / 不系统 |
| 15 | 稳定执行 | 已经成为日常,有证据可查 |
| 20 | 行业领先 | 不止自己做,还教别人 / 输出方法论 |

要求:
1. **基于 evidence,不打人情分**
2. **看行为不看意图**(问"做过几次"不是"想不想做")
3. **保守打分**:宁可少打 5 分,不要多打 5 分
4. **每个分数附 1-2 句 evidence 引用**

## 输出格式(严格 JSON,无任何额外文字)

{
  "subject": "{subject_name}",
  "scenario": "{scenario_description}",
  "evaluated_at": "{ISO date}",
  "sub_scores": {
    "A1": {"score": 15, "evidence": "..."},
    "A2": {"score": 18, "evidence": "..."},
    ...
    "D4": {"score": 8, "evidence": "..."}
  },
  "dim_summary": {
    "aesthetic": {"total": 33, "max": 80, "percent": 41, "level": "进阶段"},
    ...
  },
  "overall": {"total": 252, "max": 540, "percent": 47, "level": "进阶段 B"},
  "bottleneck": "体系(人) S2 TopN聚焦",
  "strength": "基本功 K3 智能体与RAG",
  "key_observations": [
    "AI 在 arxiv 搜索 + PDF 下载端到端跑通",
    "评分环节因 Connection error 全部失败,fallback 5.0 分",
    "mavis cron 调度链路通畅",
    ...
  ]
}
```

```
## 任务

3. **P0 改进建议**(1-3 条,每条包含):

4. **P1 改进建议**(2-4 条)

要求:
- 每条建议**可直接执行**,不写"加强 X"
- AI prompt 完整且自包含,可直接复制粘贴
- 人类清单**按时间序列**(启动前 1 小时 / 启动 / 启动后 30 分钟...)
- 期望下轮分数要保守(单轮 +10-15% 已属优秀)

## 输出格式

严格 Markdown,不要任何前言或元评论。直接输出报告 2 全文。
```

## 段位映射

```
要素百分比 = 要素总分 / 要素满分 × 100%
段位:
  初阶 < 30%
  进阶段 30-60%
  高阶 60-100%
```

## 使用流程

1. **加载 prompt**:读取本文件
2. **注入素材 + 上下文**:填 {subject_name}, {scenario_description}, {material}
3. **调 LLM**(推荐用 m3):prompt 末尾追加"输出严格 JSON"
4. **解析 JSON**:用 `scripts/auto_assess.py` 校验
5. **生成报告**:用 `scripts/generate_report.py` 把 JSON 转两份 markdown 报告
