# 01 现代明亮风格信息图

**图片数量**: 20 张

## 风格概述

明亮 / 浅色 / 鲜艳色调,适合需要传递'积极 / 科技 / 增长'情绪的信息图。主色包括:米黄 + 暗金(注意经济五维)、纯白 + 浅金(深色信息图的'轻量版')、深色 + 暗蓝夜空(如勤奋误区到 AI 赋能)。整体视觉开阔、'势能感'强,适合商业 / 科技主题。

## 图片结构

通常 2-3 层结构:1) 顶部大标题 + 副标题,2) 中心信息图主体(网络拓扑 / 多模块 / 3D 概念 / 信息图块),3) 周边小标题 + 简短说明。同系列(同一 base64 项目)的图风格一致,可做一组配图。

## 适合配图的主题

- 商业 / 科技 / 增长主题(注意力经济、用户增长、营销模型、IP 飞轮)- 抽象模型拆解(理论模型、5 步法、4 阶段论、决策树)- 强情绪正向叙事(突破、转折、增长、激活)

## 适合配图的场景

适合调性:**明亮 + 增长 + 势能**。适合:商业评论、深度长文、模型拆解文、产品分析、行业洞察、科技 / 互联网主题。不适合:情绪沉重的故事、严肃历史题材、温情随笔。
