# 04 ArtDeco 复古商务海报

**图片数量**: 17 张

## 风格概述

Art Deco 装饰艺术风格 + 商务/历史叙事,色调以 sepia / 金 / 深蓝 / 暖棕为主。
包含多个子风格:
- Art Deco 装饰 + 商务人物(代表:IBM 6 张,1920-1940 年代西装人物 + 装饰边框 + 商业期刊封面感)
- 19 世纪美国街景(代表:WSJ 6 张,sepia 色调 + 1889 年纽约街景 + 报童)
- 19 世纪水彩(代表:BSE 1 张,孟买商人树下交易 + 暖色水彩)
- 政治漫画 / 报纸印刷感(代表:trust_infrastructure 5 张,深色钢笔 + 骷髅头警示 + 19 世纪政治漫画)
- 古典油画历史场景(代表:blue_shell_network 5 张,1785 大陆会议 + 烛光 + 油画)
视觉上厚重、严肃、有'老式海报'的仪式感,适合讲百年企业 / 商业人物 / 严肃历史。

## 图片结构

通常是 sepia / 暖棕色调 + 装饰性边框 + 居中大标题 + 古典人物群像 + 古典建筑 / 物件。
- Art Deco 商务海报:1920-1940 年代西装人物 + 装饰边框 + 金/深蓝色块
- 19 世纪美国街景:1880-1890 年代纽约/费城 + 报童 + 马灯 + 旧建筑
- 政治漫画:sepia 钢笔 + 骷髅头 + 文字警告 + 商人场景
- 古典油画:1780-1800 年代烛光室内 + 长桌 + 古典服装人物

## 适合配图的主题

- 百年企业 / 经典品牌(IBM、AT&T、可口可乐、迪士尼等)
- 商业人物 / 商业精神 / 商业哲学(创始人故事、商业信仰)
- 企业史 / 品牌史(从过去到现在的叙事)
- 19 世纪商业史 / 食品安全史 / 媒体历史
- 历史事件复盘(1785 大陆会议、华尔街日报创刊)
- 价值观类叙事(诚信、效率、专业、追求)

## 适合配图的场景

适合调性:厚重 + 仪式感 + 历史感。适合:企业传记、商业人物特写、百年品牌复盘、商业价值观文章、严肃历史叙事。不适合:快节奏互联网产品、轻松生活方式、当下热点。

## 备注

本类实际是个'复古商务/历史'混合类,放在一起的图风格都比较严肃厚重,适合做'开篇图 / 总结图',不建议密集用。
