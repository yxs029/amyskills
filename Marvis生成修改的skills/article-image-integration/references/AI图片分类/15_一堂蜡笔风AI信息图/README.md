# 15 一堂蜡笔风 AI 信息图

**图片数量**: 6 张

## 风格概述

蜡笔手绘风信息图,白色背景 + 手绘蜡笔图标 + 3 个色块(蓝/橙/绿)+ 3 阶段说明(事情经验 / 可迁移能力 / 元能力)。
视觉像老师手写板书或儿童绘本,亲切、易懂、有教学感。'一堂'专属——这是一堂(教学产品)的设计语言,适合讲'学习 / 成长 / 能力'类主题。

## 图片结构

通常是白色背景 + 手绘蜡笔线 + 3 个色块并列 + 底部大句总结。
- 背景:纯白或米白
- 图标:蜡笔手绘风 + 蜡笔笔触(不规则线条)
- 色块:浅蓝 / 浅橙 / 浅绿 三个并列
- 文字:手写感字体 + 简洁大句

## 适合配图的主题

- 学习方法 / 能力成长 / 经验沉淀(事情经验 / 可迁移能力 / 元能力)
- 教学课程 / 知识体系类(讲清楚一个概念)
- 个人成长 / 终身学习类(升级、复盘、积累)
- 任何需要'亲切 + 教学感'的内容

## 适合配图的场景

适合调性:亲切 + 教学 + 成长。适合:学习方法、课程内容、成长类。不适合:严肃商业、冲突类、警示类。

## 备注

本类是'一堂'专属设计语言(蜡笔 + 三色块),识别度高——做'教学/课程'类内容时优先选。其他主题慎用,容易显得不专业。
