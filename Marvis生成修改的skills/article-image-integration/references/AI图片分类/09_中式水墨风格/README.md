# 09 中式水墨风格

**图片数量**: 7 张

## 风格概述

中式水墨山水 / 仙境风,以泼墨山水 + 古代建筑 + 飘逸装饰文字为主。
典型代表:七岛图(霜雪之岛/翡翠之岛/碧潮之岛/培火之岛/金曜之岛/流沙之岛/云梦之岛)——7 座风格各异的小岛,用虚线连接成网络拓扑。视觉是水墨 + 古风 + 现代网络拓扑的混搭。

## 图片结构

通常是水墨山水 + 多个岛屿/地点 + 虚线连接(像航海图或网络图)+ 竖排古风文字标签。
- 背景:泼墨山水 + 云雾 + 留白
- 主体:7 座小岛(每座风格不同,代表不同主题/特征)
- 文字:竖排古风 + 印章

## 适合配图的主题

- 中式主题 / 国风 / 古典文学(山海经、传统哲学)
- 网络效应 / 平台 / 生态系统(用 7 岛隐喻 7 个节点)
- 多元 / 多元宇宙 / 多 IP(7 个独立小世界)
- 古今融合话题(传统 + 创新)

## 适合配图的场景

适合调性:古风 + 仙境 + 多元。适合:中式主题、网络生态、多元叙事、文化跨界。不适合:纯西方商业场景、纯科技 IT。
