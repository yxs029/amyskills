# 05 90 年代怀旧纪实

**图片数量**: 5 张

## 风格概述

90 年代真实场景纪实风,色调暖光、灯光感强、纪实摄影质感、有'那个年代'的颗粒感。
本类实际只有 5 张,主要是 qwerty_keyboard(钢笔复古概念)、jingdong_618(京东 90 年代场景)、windows98_bsod(Win95 蓝屏)——但部分图实际是不同风格混入(如 jingdong chapter01 实际是 90 年代纪实,jingdong chapter03 实际是深色信息图)。

## 图片结构

90 年代中国实景:密集招牌、人物群像、柜台陈列、暖色灯光,接近新闻纪实摄影。
科技产品:CRT 显示器、像素感界面、IBM 复古机箱、Windows 95 蓝屏特写、键盘细节。
复古钢笔:sepia 调 + 概念符号 + 对比构图。

## 适合配图的主题

- 互联网早期 / 中国互联网史(1998 海龙大厦、京东 618 起源)
- 科技产品复盘(Windows 95 蓝屏、IBM 复古硬件)
- 90 年代商业叙事(改革开放、创业第一代)
- 怀旧话题 / 回忆杀 / 童年 / 青春类内容

## 适合配图的场景

适合调性:怀旧 + 真实 + 时代感。适合:90 年代商业史、互联网早期、改革开放叙事、怀旧产品、童年/青春回忆。不适合:前卫科技、未来趋势、当下热点。

## 备注

本类实际只有 5 张,且混入了一些其他风格图(jingdong chapter01 的纪实感、qwerty chapter02 的钢笔复古等)。选图时注意:**优先看 02_现代深色信息图**(京东618 的另一部分图在那里)。
