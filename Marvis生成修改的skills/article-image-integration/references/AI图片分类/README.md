## 分类小问题说明

实际分类中有些许'误分类'(同一 base64 项目的图风格不同):

- 03_19世纪欧美复古 只有 6 张——大部分'复古'图(WSJ / IBM / blue_shell 等)被归到 04_ArtDeco
- 05_90年代怀旧纪实 只有 5 张——jingdong_618 的另一部分图在 02_现代深色信息图
- 06_现代生活化插画 只有 5 张——大部分 getihu_1981 / jingdong_618 图在 02 类
- 04_ArtDeco 17 张是'复古 + 商务 / 历史'的混合类

选图时**优先看大分类(02 / 04 / 13 / 01)**,这些是主力的;小分类(03/05/06/08/15)适合做特色图。

## 使用建议

1. 先看自己的文章调性,选 1-2 个最匹配的分类
2. 进分类文件夹看图,选具体章节图(同 base64 项目的图风格一致,适合做一组)
3. 也可以跨分类混搭(例:开篇用 04 复古图,中间用 02 商业图,结尾用 01 信息图)
4. 配图后用 wechat-article-compliance-checker skill 检查违禁词
