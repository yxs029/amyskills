## 二、AI 常见模板化表达词库（命中越多，"AI 痕迹"越明显）

### 2.1 空话 / 套话（高频预警）
不容忽视、值得深思、具有重要意义、至关重要、由此可见、总而言之、毋庸置疑、
赋能、抓手、心智、底层逻辑、长期主义、认知、维度、颗粒度、对齐、闭环、
在这个快节奏的时代、随着社会的不断发展、近年来、众所周知

### 2.2 套路结构（句式级预警）
- 数字罗列："三个方面 / 五大趋势 / 三大要点 / 六个方法 / 十大建议"
- 并列套路："一方面……另一方面……"、"首先……其次……最后……"
- 总结套路："总之，XXX 才是核心"、"归根结底，XX 才是关键"
- 开头套路："大家好，今天我们来聊聊……"、"在 XX 领域，有一个不容忽视的现象……"

### 2.3 标题公式黑名单（同质化高风险）
- "《XX》大结局：XX 至死不知，最可怕的不是……而是……"
- "震惊！XX 竟然……"、"原来 XX 才是……"、"建议所有人都去……"
- "90% 的人都不知道的 XX"、"懂了这 N 点，你就赢了"

> 命中任意一条标题公式 + 多篇同结构 → 标"模板化程度=高"。

## 三、信息增量自检 5 问（逐篇打钩，少于 3 个勾 = 信息密度低）

- [ ] 有**明确核心观点**吗？（不是"XX 很重要"这种废话）
- [ ] 有**具体数据 / 真实案例**吗？（非虚构、非"据说"）
- [ ] 有**可验证来源 / 出处**吗？（链接、书名、作者、时间）
- [ ] 有**"我"的经历 / 看法 / 反思**吗？（个人经验、反常识观点）
- [ ] 有**可落地的方法 / 行动建议**吗？（读者看完能做什么）

勾选 ≤ 2 → 信息密度=低，强烈不建议直接发布。
勾选 3–4 → 信息密度=中，建议补充缺失项。
勾选 5 → 信息密度=高。

## 四、AIGC 使用方式风险矩阵

| 使用方式 | 风险等级 | 是否建议 | 是否建议声明 AI 辅助 |
| --- | --- | --- | --- |
| AI 生成初稿 + 人工大幅改写 + 加入个人经验 | 低 | 是 | 建议声明 |
| AI 生成部分内容 + 人工补充观点、数据、案例 | 中低 | 是（严格审核事实） | 建议声明 |
| 直接复制 AI 生成文字，仅做少量润色 | 高 | 否 | 必须声明且需重构 |
| AI 生成文章主体 + 批量 / 定时发布 | 高 | 否 | 属"非真人自动化创作"（命中即走下方"非真人自动化风险例外"规则）|
| AI 生成图片作为主体 + 配文无增量 | 高 | 否 | 需重构 |
| AI 作为工具，分享提示词 / 方法 / 经验 | 低 | 是 | 建议声明 |

> **法律边界**：即使标注"AI 生成"，虚假宣传、侵权、诽谤等内容仍由发布者担责。
> **平台边界**：2026.3.27《微信公众平台运营规范》新增"非真人自动化创作行为"专项条款，
> 明确打击：① 脱离真实创作者表达用 AI 生成/改写/搬运；② 脚本/程序托管批量连续发布；③ 传播此类教程/服务。

## 六、给模型的执行清单（Step 3 速查）

1. 算信息密度：勾"自检 5 问"，给 高/中/低。
2. 查模板化：扫标题公式黑名单 + 段落结构雷同 → 模板化程度。
3. 查 AI 痕迹：数第二节词库命中数 → 明显/轻微/无。
4. 查搬运：是否大段复述 / 截图搬运 / 缺个人观点。**（不进入加权公式，仅作风险项记录在报告「低创作度风险评估」章节）**
5. 查非真人自动化：是否 AI 主体 + 批量定时 + 推 AI 代运营服务。
6. 给声明建议：是否建议标注"本文部分内容由 AI 辅助生成"，位置文首/文末/图注。
7. 算加权总分：按第七节权重表 → 低创作度风险 高/中/低。
8. 写账号健康度建议：避免同质化、增个人故事/案例/数据、降频提质。

## 七、加权评分权重表（用于 Step 3 第 7 项）

四项子分 → 加权 → 低创作度风险等级。子分取值统一映射为分值（0=好，2=差）：

| 子分 | 权重 | 取值 | 映射分值 |
| --- | --- | --- | --- |
| 信息密度 | 40% | 高 / 中 / 低 | 0 / 1 / 2 |
| 模板化程度 | 20% | 无 / 轻微 / 高 | 0 / 1 / 2 |
| AI 痕迹 | 20% | 无 / 轻微 / 明显 | 0 / 1 / 2 |
| 个人观点 / 经验 | 20% | 充足 / 一般 / 缺失 | 0 / 1 / 2 |

**加权总分 = 0.4×信息密度 + 0.2×模板化 + 0.2×AI痕迹 + 0.2×个人经验**，范围 0 ~ 2：

- **[0, 0.6]** → 低创作度风险 = **低**
- **(0.6, 1.2]** → 低创作度风险 = **中**
- **(1.2, 2.0]** → 低创作度风险 = **高**

> 例外（不套公式，直接定级）：若「非真人自动化风险」命中
> （AI 生成主体 + 批量/定时发布 + 推广 AI 代运营服务）→ 低创作度风险**直接升为"高"**，
> 并在报告中提示"属账号维度风险，单篇改写无法根本解决"。

> 示例：信息密度=低(2)、模板化=高(2)、AI痕迹=明显(2)、个人经验=缺失(2)
> → 总分 = 0.4×2+0.2×2+0.2×2+0.2×2 = 2.0 → 风险=高。
