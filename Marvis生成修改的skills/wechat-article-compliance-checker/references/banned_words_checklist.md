# 微信公众号违禁词与违规行为对照规则 Checklist

本文档综合了《微信小店「虚假宣传-使用广告禁用词」违规治理细则》、《互联网用户公众账号信息服务管理规定》、《微信个人账号使用规范》以及2025年最新《广告法》及网络调研数据，为您提供一份全面的微信公众号文章违禁词与违规行为排查指南。在发布文章前，请务必逐项对照自查，以避免文章被删、限流或账号被封禁。

## 一、 广告法与极限词违规（高频重灾区）

在商品推广、商业软文或日常描述中，严禁使用绝对化、夸大或无法考证的极限词汇。

### 1. “最”类极限词
- [ ] **排查词汇**：最、最佳、最具、最赚、最优、最优秀、最好、最大、最大程度、最高、最高级、最高档、最奢侈、最低、最低级、最低价、最便宜、最流行、最受欢迎、最时尚、最聚拢、最符合、最舒适、最先、最先进、最新等。
- [ ] **替换建议**：使用“较”、“优选”、“先进”、“同类产品性价比高”等客观描述。

### 2. “一”类极限词
- [ ] **排查词汇**：第一、中国第一、全国第一、全网第一、销量第一、排名第一、行业第一、TOP.1、仅此一家、仅此一次、仅此一款、唯一、全网唯一、独一无二、一流、全国X大品牌之一、世界X大品牌之一。
- [ ] **替换建议**：使用“名列前茅”、“行业佼佼者”、“少有”等。

### 3. “级/极/顶”类极限词
- [ ] **排查词汇**：国家级、全球级、宇宙级、世界级、极品、极佳、极致、顶级、顶尖、尖端、顶级工艺、顶级享受、终极等。
- [ ] **替换建议**：使用“高端”、“精致”、“精湛”、“优异”等。

### 4. 绝对且无法考证的表述
- [ ] **排查词汇**：世界领先、行业领先、领先上市、领导者、缔造者、王者、至尊、巅峰、性价比之王、顶级工艺、王牌、销量冠军、绝无仅有、前无古人、史无前例、万能、绝对、无限、永久、完美、100%、正品等。
- [ ] **替换建议**：使用"在同类中较为靠前""经第三方核验""行业前列""有据可查"等可验证、有限定范围的表述，避免使用绝对化、不可证伪的用语。

## 二、 虚假宣传与诱导消费

### 1. 滥用权威背书
- [ ] **排查词汇**：国家领导人推荐、国家机关推荐、国家机关特供、军队或相应缩写、国家免检、政府定价、特供/专供、老字号（未获认证）、中国驰名商标、专家推荐、质量免检、无需国家质量检测、免抽检、使用人民币图样。

### 2. 虚假承诺与高风险诱导
- [ ] **排查词汇**：包过、一本书学会、一套题学会、一次通过、一次通关保过、高考升学率、高考移民、立马升值、投资价值、投资回报、稳赚不赔、高收益。

### 3. 虚假时限与制造焦虑
- [ ] **排查词汇**：限时（无具体时限）、仅限、抢疯了、秒杀、卖疯了、再不抢就没了、万人疯抢、XX秒、随时结束、仅此一次、随时涨价、马上降价、最后一波。
- [ ] **替换建议**：所有限时活动必须标明具体的活动起止日期。

## 三、 特定行业高危违禁词

### 1. 医疗、健康与美容类
- [ ] **排查词汇**：治愈率、有效率、老中医秘方、一针见效、抗癌特效、xx指定、推荐、xx选用、获奖、无效退款、保险公司保险、不反复、三天即愈、根治、比手术安全、包治百病、一盒见效、彻底康复、无副作用、痊愈、立马见效、100%有效、零风险、无毒副作用、无依赖、免费治疗。
- [ ] **替换建议**：使用“见效率”、“低反复”、“治疗效果较好”、“低风险”等。

### 2. 食品与保健品类
- [ ] **排查词汇**：替代母乳、预防和治疗疾病、降低血压、祖传、秘制、强力、特效、全效、强效、奇效、高效、速效、神效。
- [ ] **替换建议**：保健食品广告必须显著标明“本品不能代替药物”。不得使用与药品相混淆的词汇。

### 3. 金融理财类
- [ ] **排查词汇**：投资返利、高收益、稳赚不赔、保本高收益、低风险暴利、公开荐股、预测未来具体走势。

## 四、 诱导分享与恶意营销

微信平台对诱导分享和恶意营销打击极严，极易导致封号。

### 1. 奖励诱导分享
- [ ] **排查行为**：分享后有奖励、邀请好友拆礼盒、集赞、分享增加抽奖机会、分享后才能继续阅读或操作。

### 2. 胁迫/煽动诱导分享
- [ ] **排查词汇**：“不转不是中国人”、“请好心人转发一下”、“转发后一生平安”、“转疯了”、“必转”、“10分钟内转发给10位亲人全家平安”等带有夸张、诅咒性质的言语。

### 3. 欺诈与类似传销
- [ ] **排查行为**：多级分销、高额返利、民族大业、资产解冻、免费送礼骗邮费、网赚欺诈、兼职刷单、做任务返利。

## 五、 政治敏感、迷信与不良信息

### 1. 政治敏感词（绝对禁区）
- [ ] **排查内容**：国家领导人姓名及职务的不当表述、错误的国家机构名称、敏感历史事件、涉政谣言、反动词汇、未经批准发布时政类新闻。
- [ ] **注意**：AI检测极严，切勿使用谐音、拼音首字母、拆字等方式规避。

### 2. 封建迷信
- [ ] **排查词汇**：冥器、带来好运气、增强第六感、逢凶化吉、避凶辟邪、防小人、化解小人、增加事业运、健康富贵、提升运气、有助事业、护身、平衡正负能量、消除精神压力、调和气压、时来运转、万事亨通、镇宅、消灾、挡灾、助吉避凶、转富招福、算命、算卦、神仙、保佑等。

### 3. 黄暴低俗与黑恶势力
- [ ] **排查内容**：招嫖、包养、裸聊、色情表演、原味物品、性相关恶搞低俗文案（软色情）、脏话骂人、自虐自残、虐待动物、教唆犯罪、替人复仇、收账等。

## 六、 变体规避词与隐私侵权

### 1. 变体规避词（AI重点打击对象）
- [ ] **排查内容**：拼音缩写（如 VX 代替微信、zf 代替政府）、谐音替换（如 兼直 代替兼职、溡薪 代替时薪）、形似字。
- [ ] **替换建议**：正常表述，不要试图通过变形词绕过审核，一旦被AI语义分析识别，将面临更严厉的处罚。

### 2. 隐私与侵权
- [ ] **排查内容**：未经授权发布他人身份证号码、联系方式、家庭住址、微信号、照片等个人隐私资料；擅自使用他人企业名称或商标；捏造事实诽谤他人。

## 💡 终极发文建议

1. **发文前必查**：使用微信公众号后台自带的错别字/违规词检测功能，或借助第三方工具（如壹伴助手、句无忧等）进行全文语义扫描。
2. **避免堆砌**：即使是合规的营销词汇，也不要在标题和正文中大量堆砌，以免被判定为“低质灌水”或“过度营销”。
3. **保留证据**：如果文章中确实使用了“第一”、“唯一”等词汇（如获得了国家级真实奖项），请务必准备好相关的官方认证材料，以备申诉时使用。
