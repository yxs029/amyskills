# 方案索引报告模板（精简版 · 3000-5000 字）

> **目标读者**：患者/家属/基层医生——快速判断"这周有什么新方案可用、谁在做、去哪找"
> **不写**：药物组成/剂量/煎服法/不良反应分级/药理机制——这些在 drugs.db 库

```markdown
# {癌种}({stage}){分册名} 方案索引({YYYY-MM-DD})

> **本期焦点**：{1 句话概括本周最值得关注的 1-2 个方向}
> **本报告周期**：{起止日期}
> **报告字数**：~{实际字数}（目标 3000-5000）
>
> **本报告不含药物配方/剂量**——药物细节见 `drugs.db`（按方案 ID 查询）
> **使用前必须与主治医生讨论**——报告是信息索引，不是处方建议
```

## 模板使用注意事项

1. **严格控制字数**：3000-5000 字为目标。超了就要砍——优先保留"在哪做/找谁"
2. **表格优先**：方案映射、医院联系、渠道列表全用表格，不用长段落
3. **不展开药物**：drugs.db 是独立资产，报告只引方案 ID，不引药物组成
4. **方案 ID 唯一性**：每条方案在库里有唯一 ID，跨周跨分册保持稳定
5. **联系方式要具体**：电话/官网/公众号至少给一项，不能只说"知名医院"
6. **不引用机制研究**：药理/网络药理学/分子机制 → 进 drugs.db，不进报告
7. **不引用古籍**：方剂来源/古籍出处 → 进 drugs.db 字段，不进报告
8. **3-5 项就够**：本周新方案 5-10 条；保留项不重复（用 ➖ 标记即可）
