# 5 类文章的差异化风格微调

> 4 条思维定律 + 4 条语言定律是通用底座。不同文章类型在**权重和细节上有差异**。

---

## 类型 1：个人复盘 / 成长故事

### 定律权重

| 定律 | 权重 | 备注 |
|---|---|---|
| 坐标原点 | ⭐⭐⭐⭐⭐ | 最重要，整篇都是"我" |
| 跨领域迁移 | ⭐⭐ | 可省，因为本来就是私人叙事 |
| 具体短板 | ⭐⭐⭐⭐⭐ | 复盘的核心 |
| 主观判断 | ⭐⭐⭐ | 自然出现 |
| 节奏破坏者 | ⭐⭐⭐⭐ | 短句成段是标志 |
| 过渡词 | ⭐⭐⭐⭐ | 说远了/其实/反正 密度高 |
| 轻自嘲 | ⭐⭐⭐⭐⭐ | 复盘文的味道 |
| 直接互动 | ⭐⭐ | 不必太多，主要在收尾 |

### 特殊规则

- **可以塞私人锚点**：带娃、一堂、北辰、DISC、人生红点、觉察日志……全都可以
- **可以有深度个人故事**：具体到年月日、具体到人（张磊、企鹅君、李炜、辉辉）
- **可以有点名致谢段**：这是复盘文的标志性动作
- **章节骨架**：`### 01 XX / ### 02 XX / ### Fin. XX`（用 ### 三级+叙述小标题）
- **结尾用箴言**：不用反问，用一句朴素金句（"无限成长，始于足下""与其向外求，不如向内求"）

### 差异化 checklist

原 checklist 基础上：
- 复盘文的**"具体短板"权重加倍**（不是 5 分而是 10 分）
- **"跨领域迁移"可以给满分基线**（不是必需项）
- **"反问收束"改为箴言收束**（可以陈述句）

## 类型 2：早期商业方法论 / 抽象模型

### 定律权重

| 定律 | 权重 | 备注 |
|---|---|---|
| 坐标原点 | ⭐⭐⭐⭐⭐ | 是关键，靠这个防止变教科书 |
| 跨领域迁移 | ⭐⭐⭐⭐⭐ | 最重要，把抽象模型套到多领域 |
| 具体短板 | ⭐⭐⭐ | 有一次即可，轻度 |
| 主观判断 | ⭐⭐⭐⭐ | 需要旗帜鲜明 |
| 节奏破坏者 | ⭐⭐⭐⭐⭐ | 长段最容易变教科书 |
| 过渡词 | ⭐⭐⭐⭐ | 说白了/别急密度高 |
| 轻自嘲 | ⭐⭐ | 有一次即可 |
| 直接互动 | ⭐⭐⭐⭐ | 讲道理时持续对话 |

### 特殊规则

- **禁止强塞私人锚点**（带娃/一堂等）——除非真跟主题有关
- **必须做大白话翻译层**：概念定义后必须跟"说白了……"
- **章节骨架灵活**：可以叙述型章节名（"最佳实践的五个段位""如何归纳总结"）
- **表格可以保留**：Aaron 早期文章就爱用表格做迁移映射

### 差异化 checklist

原 checklist 基础上：
- **"大白话翻译层"独立成为一个 5 分项**（学术定义后必须跟人话）
- **"跨领域迁移"权重加倍**（10 分）
- **"具体短板"可以是轻度**（一句话即可）

## 类型 3：历史上的今天 + 商业概念

### 定律权重

| 定律 | 权重 | 备注 |
|---|---|---|
| 坐标原点 | ⭐⭐⭐⭐ | 用"我以前对 X 特别模糊"式轻锚 |
| 跨领域迁移 | ⭐⭐⭐⭐⭐ | 从历史 → 现代 → 一人公司必做 |
| 具体短板 | ⭐⭐⭐⭐ | 用"我 2023 年错过 AI 窗口"式轻锚 |
| 主观判断 | ⭐⭐⭐⭐ | 章节末必给判断 |
| 节奏破坏者 | ⭐⭐⭐⭐⭐ | "全场都傻了。"式短句独占 |
| 过渡词 | ⭐⭐⭐⭐ | 说到这里/换个角度/别急 |
| 轻自嘲 | ⭐⭐⭐ | 1 处即可 |
| 直接互动 | ⭐⭐⭐⭐⭐ | 章节末+全文末必反问 |

### 特殊规则

- **章节骨架 `#00-#05`**（这是这类文章的稳定结构）
- **章节标题叙述型**：不是"维度 1"而是"情绪造窗口"
- **开场用现场感**：年月日+地点+人物动作
- **中段引入商业概念**：用"他从这场 X 里，看到了一个更值钱的东西——**X**"
- **收尾必反问**：全文末必须以反问收束
- **私人锚点用"轻度"**：不到具体年月日，动作/环节即可

### 差异化 checklist

原 checklist 基础上：
- **"章节骨架 #00-#05"** 必须（不达标扣 5 分）
- **"章节末反问 + 全文末反问"** 双重必做
- **精确年月日** 权重加倍（历史时间必须精确到日）

## 类型 4：一人公司启示 / 反常识建议

### 定律权重

| 定律 | 权重 | 备注 |
|---|---|---|
| 坐标原点 | ⭐⭐⭐ | 可选，但有更好 |
| 跨领域迁移 | ⭐⭐⭐⭐ | 从大公司 → 一人公司必做 |
| 具体短板 | ⭐⭐⭐⭐ | "我自己也没完全做到，60 分吧" |
| 主观判断 | ⭐⭐⭐⭐⭐ | 反常识建议的核心 |
| 节奏破坏者 | ⭐⭐⭐⭐⭐ | 短句独占段是标志 |
| 过渡词 | ⭐⭐⭐⭐ | 别急/说白了/换个角度 |
| 轻自嘲 | ⭐⭐⭐ | 1 处即可 |
| 直接互动 | ⭐⭐⭐⭐⭐ | 高密度，全篇跟读者对话 |

### 特殊规则

- **痛点开场**："你有没有这种感觉：……"
- **章节标题叙述型**：不用"5 个方法"用"5 个坑，千万别再犯了"
- **章节内部小标题动词开头**："把你的产品拆成零件""找到你自己的 T 型车"
- **章节末必给可落地动作**（不是原理讲完就结束）
- **全文末必反问**+加粗

### 差异化 checklist

原 checklist 基础上：
- **"直接互动"权重加倍**（10 分）
- **"章节末可落地动作"** 独立成 5 分项
- **加粗金句密度加倍**（每 200 字 1 处）

## 类型 5：读书笔记 / 人物传记

### 定律权重

| 定律 | 权重 | 备注 |
|---|---|---|
| 坐标原点 | ⭐⭐⭐⭐⭐ | "我不怎么看书"式开场 |
| 跨领域迁移 | ⭐⭐⭐ | 从书 → 自己生活 |
| 具体短板 | ⭐⭐⭐⭐ | "我读到 XX 页放下了" |
| 主观判断 | ⭐⭐⭐⭐⭐ | 读书感悟必须旗帜鲜明 |
| 节奏破坏者 | ⭐⭐⭐⭐ | 段落短，节奏松 |
| 过渡词 | ⭐⭐⭐⭐ | 说远了/其实/我想说的是 |
| 轻自嘲 | ⭐⭐⭐⭐ | "我不常看书"就是自嘲 |
| 直接互动 | ⭐⭐⭐ | 章节末问一次即可 |

### 特殊规则

- **可以大段引用原书**：Aaron 手写样本里节选比例很高
- **章节骨架**：叙述型章节（"中国成都的普通女孩""移民的艰辛生活"）
- **章节末必给"我的思考"**：分享自己的疑问和感悟
- **收尾用"未完待续"或"你的答案是什么"**

### 差异化 checklist

原 checklist 基础上：
- **"原书引用比例"** 独立成 5 分项（合适：占 20-30%）
- **"我的思考段"** 独立成 5 分项（每章至少 1 处）
