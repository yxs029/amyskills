## 案例 1：路径依赖（QWERTY 键盘 / 类型 3 历史今天）

### AI 原文

```markdown
**路径依赖（Path Dependence）**，由经济学家保罗·戴维（Paul David）在 1985 年
的经典论文《Clio and the Economics of QWERTY》中系统论证。

他指出：**一个系统一旦选择了某条路径，就会因为自我强化机制而"锁定"在这条路径上，
即使后来出现了更优的替代方案，也难以改变。**

戴维总结了锁定效应的三大驱动因素：

1. **技术上的相互关联性**：键盘布局和打字员培训、打字机制造、办公流程形成了
   复杂的技术生态系统，改一个就得改全部。
2. **规模经济的正外部性**：用 QWERTY 的人越多，QWERTY 的价值越大（网络效应）。
3. **投资的不可逆性（沉没成本）**：学会 QWERTY 键盘需要数百小时的练习。
```

### 病灶诊断

- ✗ **违反定律 1（无坐标原点）**：没有"我"作为定位
- ✗ **违反定律 2（无跨领域迁移）**：只在键盘范围内讲
- ✗ **违反定律 5（长段+数字编号）**：1/2/3 编号，段落太长
- ✗ **违反定律 6（无思维过渡词）**：直接进定义

### Aaron 化改造

```markdown
说到这里就必须请出一个词：**路径依赖**（Path Dependence）。

说实话我第一次听到这词，是在一个学习社群的课上。

当时我脑子里冒出的是我自己的知识库——用了 3 年 Obsidian，中间试过 Notion、
飞书，每次都没换成。〔定律 1：坐标原点 + 定律 3：具体短板〕

后来一看戴维 1985 年那篇论文，我才发现这不是我一个人的毛病。

翻成人话就一句：

**踩上一条路，走着走着就下不来了。**〔定律 5：短句独占段 + 定律 6：说白了式翻译〕

这道理不光在键盘上。〔定律 2：跨领域过渡〕

你想想婚姻，你想想工作岗位，你想想你手机里那些用了 5 年舍不得删的
APP——是不是都一样？〔定律 2：跨领域迁移 + 定律 8：直接互动〕

说白了，人这种生物，一旦对某件事投入过太多，就很难承认它是错的。

**这就是我对"路径依赖"本质的理解吧。**〔定律 4：主观判断 + 谦逊修饰〕
```

### 改造点位对照

| 位置 | 用了什么定律 |
|---|---|
| "说到这里就必须请出一个词" | 定律 6：思维过渡词 |
| "说实话我第一次听到这词" | 定律 1：坐标原点铺垫 |
| "用了 3 年 Obsidian，中间试过 Notion、飞书" | 定律 3：具体短板（有次数） |
| "翻成人话就一句" | 定律 6：大白话翻译层 |
| "踩上一条路走着走着就下不来了" | 定律 5：节奏破坏者 + 金句 |
| "你想想婚姻/工作岗位/手机 APP" | 定律 2：跨 3 个远领域 |
| "说白了，人这种生物……" | 定律 6：说白了 |
| "**这就是我对……的理解吧**" | 定律 4：主观判断 + 吧 |

## 案例 2：造节经济（618 / 类型 3）

### AI 原文

```markdown
造节经济，指企业或平台通过人为创造具有仪式感的消费时间节点，将分散的自然需求
压缩到特定时段集中释放，从而实现交易规模大幅增长的商业策略。
```

### 病灶诊断

- ✗ **违反定律 5**：一句话 45 字，无节奏
- ✗ **违反定律 6**：学术定义式表达
- ✗ **违反定律 8**：无直接互动

### Aaron 化改造

```markdown
造节经济说穿了就一句话：

**打折只改变了价格，造节改变了时间本身。**〔定律 5+定律 6+加粗金句〕

你想想，5 月 20 号那天你会不会突然给谁转 520？〔定律 8：直接互动〕

这钱本来可以在别的日子转的，但你就是想那天转。

商家的算盘就是这个——**不是让你多花钱，而是让你在指定的那一天花钱。**〔定律 4+加粗〕

说远了。〔定律 6：思维过渡〕

学术上定义得复杂——"人为创造仪式感消费节点，将分散需求压缩到特定时段……"
——但意思就是上面这句。
```

### 关键操作

- 学术定义**放到最后**作为补充，前置金句
- 用"5 月 20 号转 520"做**日常场景锚**（比"618"更普世）
- 用"说远了"暴露作者的思维跳跃

## 案例 3：反定位（Target / 类型 3）

### AI 原文

```markdown
**反定位的本质是战略柔道，挑战者利用霸主成功的重量，反过来压制霸主。**

霸主的利润结构、合作关系、品牌定位、组织惯性，全部变成了它无法反击的枷锁。
```

### 病灶诊断

- ✅ **加粗金句已经不错**（"战略柔道"是好比喻）
- ✗ **违反定律 2**：缺跨领域迁移
- ✗ **违反定律 3**：缺具体短板
- ✗ **违反定律 8**：缺互动

### Aaron 化改造

```markdown
反定位听起来玄，其实就是**战略柔道**——你不硬跟对手正面打，你借着对手的力
把对手摔出去。〔平铺+加粗金句〕

我给你举个不商业的例子。〔定律 2：跨领域过渡〕

你有没有见过公司里那个"死不加班"的同事？大家都在卷 996，就 TA 每天 6 点
准时下班，还升职比谁都快。〔定律 2：跨领域 + 定律 8：直接互动〕

老板明知道 TA 这么干，为啥不管？

因为管了就得让所有人都不加班，那老板另外那套"卷文化"的资产就废了。

这就是反定位。〔定律 5：单句成段收束〕

对方看得见你在干嘛，但**动一下就砸自己的锅，只能装看不见。**〔加粗金句〕

我自己在公司也试过这招，说实话没成，因为我太在乎老板的看法，绷不住。〔定律 3：具体短板 + 定律 7：轻自嘲〕
```

### 关键操作

- 从"Target vs 沃尔玛"→ 迁移到"打工人日常"（**跨领域跨得远**）
- **明确说"我自己也试过"**：坐标原点 + 具体短板
- **说"没成，因为我太在乎老板"**：具体到原因

## 案例 4：福特主义（类型 3）

### AI 原文

```markdown
福特主义是一套完整的商业操作系统：它把产品标准化、把工序拆解到非常精细、
把工资提上去让工人买得起自己造的东西、把工时降下来让人有生活。
```

### 病灶诊断

- ✅ **相对不错**（有节奏、有加粗铺垫）
- ✗ **违反定律 1**：缺坐标原点
- ✗ **违反定律 4**：缺主观判断+谦逊修饰

### Aaron 化改造

```markdown
很多人以为福特主义 = 流水线。

没那么简单。〔定律 5：短句独占段〕

我第一次读福特的传记是 2 年前，读完的第一感觉是——这个人根本不是在造车，
**他是在设计一整套经济齿轮。**〔定律 1：坐标原点 + 加粗金句〕

拆开看是 4 步：产品标准化 → 工序精细化 → 工资涨上去 → 工时降下来。

4 步环环相扣。

**说白了，福特一手造出了工厂里那个能自我循环的钱袋子。**〔定律 6：说白了 + 加粗主观判断〕

当然我这理解可能过度浓缩了，学界肯定会有争议。〔定律 4：谦逊修饰〕
```

### 关键操作

- 加"**我 2 年前读福特传记的第一感觉**"—— 定律 1 的经典模板
- 加"当然我这理解可能过度浓缩了"—— 定律 4 的经典模板

## 案例 5：爱迪生专利帝国（类型 3）

### AI 原文

```markdown
**爱迪生以为专利是让对手进不来的城墙，没想到这堵墙同时也是一个笼子，把他困在了旧规则里。**
```

### 病灶诊断

- ✅ **这句已经很 Aaron**（有比喻、有反转）
- ✗ **整篇缺定律 2**：跨领域迁移
- ✗ **整篇缺定律 3**：具体短板

### Aaron 化补充段

在这句加粗金句**后面**加：

```markdown
爱迪生以为专利是让对手进不来的城墙，没想到这堵墙同时也是一个笼子。

我做副业的时候也差点犯这种病。〔定律 2：跨领域迁移 + 定律 3：具体短板〕

前年我做了一套复盘方法论，好不容易积累了几十个案例。

当时我第一反应是：**要不要把这个包装成付费课，只卖给学员？** 藏起来，
别人偷不走。

我犹豫了半年。

后来试着开源了一部分，反倒把上下游合作方全带出来了。

藏着掖着的那段时间，是我做副业最没进展的半年。〔定律 3：具体短板收束〕

这么看爱迪生，我一点都不觉得他傻——他只是走了一条我们大多数人第一反应
会走的路。〔定律 4：主观判断 + 谦逊〕
```

### 关键操作

- 从"爱迪生的专利战"→ 迁移到"我做副业的选择"（跨领域跨得远）
- 用"我犹豫了半年"、"最没进展的半年"—— 定律 3 的具体短板
- **翻转对爱迪生的评价**："我一点都不觉得他傻"—— 定律 4 的旗帜鲜明判断

## 通用病灶速查表

改稿时先扫一眼这个表，对号入座：

| 病灶症状 | 违反的定律 | 修复方法 |
|---|---|---|
| 定义前直接进"XX 是 XX" | 定律 1 缺坐标 | 加"说实话我第一次听到这词是懵的" |
| 只在一个行业里讲 | 定律 2 缺迁移 | 加"这道理不光在 X 上，你想想 Y" |
| "仍需努力"式承认 | 定律 3 缺短板 | 加"我尝试 N 次，都在 XX 步卡住了" |
| "综上所述"总结 | 定律 4 缺主观 | 加"这就是我对 X 的理解吧" |
| 段落超过 6 行 | 定律 5 无节奏 | 拆成 1-3 行 + 单句独占段 |
| "首先/其次/再者" | 定律 6 作文式 | 改成"其实/说白了/说远了" |
| 全篇无自嘲 | 定律 7 缺自嘲 | 加"贪心/惭愧/硬着头皮" 1 处 |
| 只有陈述句 | 定律 8 缺互动 | 加"你有没有""你想想" 3-5 处 |
| 章节内 1/2/3 编号 | 结构 AI 味 | 改叙述型小标题 |
| 加粗全是术语 | 加粗类型错 | 改成"颠覆性总结句" |
| 结尾陈述句 | 缺反问收束 | 改成"你的 X 是什么？" |
| "众所周知/毋庸置疑" | 禁用词 | 直接删除 |

## 病灶诊断流程

1. **通读一遍**，先记录整体印象（像不像 Aaron 说话）
2. **对照病灶速查表**，找出所有违反项
3. **按定律权重排序**：先修⭐⭐⭐⭐⭐ 的定律，再修⭐⭐⭐⭐
4. **一处一处改**，每改一处标注用了哪条定律
5. **改完再评分**：不达 95 分继续下一轮
