# 5 类文章的开场模板

> 先判断文章类型，再挑对应开场。开场决定 30% 的"人味感"。

---

## 类型 1：个人复盘 / 成长故事

### 使用场景

年终复盘、里程碑复盘、阶段总结、成长故事系列。**这是唯一可以塞私人锚点（带娃/一堂/北辰/DISC）的类型**。

### 三段自介开场模板（Aaron 稳定模板）

```markdown
# {标题}

---

转眼，{时间点}就这么过了，其实我从{起点}就开始想写{主题}。

刚开始{从 X 角度}写，洋洋洒洒，写了 N 稿，无法过我自己这一关。

我后来发现还是按照{Y 角度}写才是对的。

于是，我拆成了 N 篇{类型}，也作为{目的}送给自己吧。

![Image](...)

嗨！你好呀，我喜欢搭建知识库，因为这是我不断成长的基础也是动力源泉。

我叫 Aaron，叫我雪松也行。

这是我送给自己 {年份} 年的新年礼物，希望对你也有启发。

---
```

### 变体

- 事件复盘型："{时间}那天，{事件}。我一直想复盘这件事……"
- 项目复盘型："这个项目我做了{时长}，今天想说说……"

---

## 类型 2：早期商业方法论 / 抽象模型

### 使用场景

讲一个抽象概念（IPO 模型/最佳实践/成本创新/网络效应），偏教科书类。

### "你有没有想过"共情开场

```markdown
# {标题}

---

你有没有想过一个问题：{反常识提问}？

{2-3 句展开背景}

其实答案很简单：{一句核心结论}

今天我们就来拆一拆，{主题}到底是什么。

---
```

### 变体

- 焦虑切入型："{现象描述}。是不是{读者可能的焦虑}？"
- 案例切入型："{某公司/某人}做了一件事：{动作}。结果……"

**注意**：这类文章禁止强塞私人锚点，坐标原点用"我以前对 X 的理解特别模糊"式**轻锚**。

---

## 类型 3：历史上的今天 + 商业概念

### 使用场景

用"XXXX 年 X 月 X 日"开头，讲一个历史事件 + 提炼一个商业概念 + 一人公司启示。

### 场景现场开场

```markdown
# {标题}

### #00 {年月日}，{地点}，{一句核心事件}

{年份}年{月}月{日}日，{地点}。

{主角}{做了一个具体动作}。

{一句强化的关键数字或结果}。

{全场/所有人的反应，用短句}。

全场都傻了。 或 一天，涨了 X%。 或 卖了 XX 亿美元。

{主角的心态/反差}

他/她从这场{事件}里，看到了一个更值钱的东西——**{商业概念}**。

今天我们用 {N 年后} 的视角回看这场{事件}，提炼一个被忽略的商业概念，{概念}。

然后聊聊它怎么套用在一个人的公司上。

---

### #01 {叙述型小标题}
```

### 关键动作

- **年月日精确到日**（不是"某年"）
- **地点具体**（不是"美国"，而是"纽约时代广场"）
- **反应用短句独占段**（"全场都傻了。"）
- **文末点出商业概念作为钩子**（"他看到了一个更值钱的东西"）

---

## 类型 4：一人公司启示 / 反常识建议

### 使用场景

"5 个坑""5 把钥匙""反常识建议""避坑指南"等直接面向创业者/一人公司的方法论。

### 痛点共情开场

```markdown
# {标题}

---

你有没有这种感觉：{痛点描述 3-5 项，用短句列出}

其实，你可能忽略了一个关键问题：

**{一句反常识的核心洞察}**

今天我们就来拆一拆，{参考对象}是怎么做到的。

---

### #00 {历史今天引子（可选）}或直接进 #01
```

### 变体

- 更狠型："做{一人公司/搞副业}的都该醒醒，{反常识主张}"
- 承认现实型："{描述某种大家都在犯的错}——你有没有中招？"

### 与类型 3 的差别

- 类型 3：**先讲历史，再提炼概念，最后给启示**（学术+故事+建议）
- 类型 4：**先痛点共情，直接给方法论**（不一定挂历史事件）

---

## 类型 5：读书笔记 / 人物传记

### 使用场景

分享一本书、一个人物、一个人物传记的核心思想。

### 引子开场

```markdown
# {书名/人物}读书笔记：{副标题}

---

我不怎么看书，一般都是听书，但是这本书，我觉得值得读一读。

也把自己的读书笔记分享出来，希望你有缘读到它。

这本书有{N}条线：{线 1}和{线 2}。

我把这本书拆成：{切割方式}。

好，我们开始吧~

---

### {叙述型章节名}
```

### 关键动作

- 承认自己"不常看书"（轻自嘲）
- "希望你有缘读到它"（softer 邀请）
- "我们开始吧~"（拉开距离感）

---

## 开场选择决策树

```
文章主题是……
│
├─ 个人经历/成长/复盘 → 类型 1（三段自介）
│
├─ 抽象商业概念（无历史事件锚点）
│   │
│   ├─ 偏教科书理论 → 类型 2（你有没有想过）
│   └─ 偏一人公司实操 → 类型 4（痛点共情）
│
├─ 有明确历史事件锚点（某年某月某日）→ 类型 3（场景现场）
│
└─ 讲一本书/一个人 → 类型 5（读书笔记引子）
```

## 开场的通用禁忌

无论哪种类型，开场都不能：

- ❌ 用"在当今时代""在这个信息爆炸的年代""随着 XX 的发展"
- ❌ 用"我今天要给大家分享的是……"
- ❌ 用"众所周知……"
- ❌ 用大段术语堆砌（>3 行不出现具体人/事/场景）
- ❌ 用礼貌客套（"大家好，感谢关注"）

## 开场的通用必做

- ✅ 前 3 行必须有**具象**元素（人/时间/地点/数字/场景中至少 1 个）
- ✅ 前 5 行必须有**至少 1 处短句独占段**
- ✅ 前 10 行必须出现**读者视角**（"你"/"我们"至少 1 次）
