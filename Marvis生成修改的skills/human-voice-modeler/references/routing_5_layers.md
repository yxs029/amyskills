# 5 层路由决策表

> **v2 核心创新**：输入"主题+用户+偏好味"，5 层路由输出"X% Y 味 + Z% W 味"组合配方。

---

## 路由总览

```
[输入] 主题 + 用户画像 + 偏好味
   ↓
[第 1 层] 主题分类
   ↓
[第 2 层] 主题角度
   ↓
[第 3 层] 用户画像反推
   ↓
[第 4 层] 味道组合
   ↓
[第 5 层] 强度调整
   ↓
[输出] 组合配方 + 调优参数
```

---

**输入**：主题关键词
**输出**：6 大类之一

| 分类 | 关键词触发 | 输出 |
|---|---|---|
| **复盘类** | 复盘 / 成长 / 年终 / 项目 / 那年我 / 工作 N 年 | 复盘类 |
| **商业知识类** | 商业 / AI / 方法 / 工具 / 产品 / 创业 / 一人公司 / 思维模型 | 商业知识类 |
| **历史今天类** | 历史 / 今天 / 那年 / 纪念 / 诞辰 / 工业 / 革命 | 历史今天类 |
| **读书笔记类** | 读书 / 书评 / 笔记 / 读后 / 拆书 / 推荐书 | 读书笔记类 |
| **散文类** | 散文 / 随笔 / 生活 / 情感 / 陪伴 / 写给 / 那时 | 散文类 |
| **时评/转述类** | 科技 / 趋势 / 经济 / 未来 / 翻译 / 解读 / 硅谷 | 时评/转述类 |

**默认权重**：输入主题 → 关键词匹配 → 选最高分类（可手动调整）

## 第 2 层：主题角度分析

**输入**：第 1 层分类
**输出**：5 大角度之一（可叠加）

### 5 大角度定义

| 角度 | 核心句式 | 关键词 | 优先级 |
|---|---|---|---|
| **反常识** | "X 其实是 Y" | 颠覆 / 其实 / 真相 / 别被骗 / 99% / 反转 | 高 |
| **方法** | "5 个 XX" / "如何 XX" | 方法 / 步骤 / 套路 / 复盘 / 总结 / 提炼 | 高 |
| **复盘** | "我做 XX 的 N 年" | 我 / N 年 / 经历 / 踩坑 / 故事 / 回忆 | 中 |
| **对位** | "X vs Y" / "古今对比" | 对比 / 一样 / 不同 / 差距 / 量级 / 跨时代 | 中 |
| **情感** | "我 XX 时的感受" | 感受 / 心情 / 那个 / 那年 / 想念 / 陪伴 | 低 |

**单篇文章可叠加 1-2 个角度**（如"反常识+对位"、"方法+复盘"）。

**默认分配规则**：
- 复盘类 → 主"复盘" + 辅"情感"
- 商业知识类 → 主"方法" + 辅"反常识"
- 历史今天类 → 主"对位" + 辅"反常识"
- 读书笔记类 → 主"对位" + 辅"情感"
- 散文类 → 主"情感" + 辅"复盘"
- 时评/转述类 → 主"反常识" + 辅"方法"

**输入**：第 3 层用户画像 + 第 2 层角度
**输出**：味道组合配方（百分比）

| 味道 | 核心特征 | 代表作者 |
|---|---|---|
| **Aaron 味** | 自我暴露 + 模型化 + 谦逊 + 商业+复盘双轨 | Aaron（雨小月）|
| **L 味** | 步骤化 + 工具化 + 案例化 + 实用方法派 | L 先生 |
| **刘澜味** | 古典引用 + 双向对话 + 思考题 + 学者对位派 | 刘澜 |
| **不懂经味** | 硅谷一手 + 高密度 + 反常识 + 商业转述派 | 不懂经 |
| **和菜头味** | 情感散文 + 时空锚 + 物理动作 + 散文家 | 和菜头 |

### 7 大典型组合场景

| # | 主题 | 用户 | 组合配方 |
|---|---|---|---|
| 1 | 复盘类（个人成长）| 焦虑中层 | 70% Aaron + 30% L |
| 2 | 商业知识（方法）| 学习者 | 70% L + 30% Aaron |
| 3 | 商业知识（反常识）| 想破局的人 | 50% 不知 + 50% Aaron |
| 4 | 历史今天（商业）| 想学历史的 | 50% 不知 + 50% Aaron |
| 5 | 读书笔记（对位）| 求深度的 | 70% 刘澜 + 30% Aaron |
| 6 | 散文（情感）| 想被陪伴的 | 70% 和菜头 + 30% Aaron |
| 7 | 转述（反常识）| 找高密度信息 | 80% 不知 + 20% 刘澜 |

### 决策规则

**主味选择**：
- 主题角度=反常识 → 不知味权重高
- 主题角度=方法 → L 味权重高
- 主题角度=复盘 → Aaron 味权重高
- 主题角度=对位 → 刘澜味权重高
- 主题角度=情感 → 和菜头味权重高

**辅味选择**：
- 任何组合都加 20-30% Aaron 味（保底，确保有"我"）

**例外**：
- 强情感散文 → 和菜头味 ≥70%
- 强反常识商业 → 不知味 ≥60%
- 强方法论 → L 味 ≥60%

## 第 5 层：强度调整 + 覆盖机制

**输入**：第 4 层组合 + 用户偏好
**输出**：最终强度（0-100%）+ 用户覆盖

### 强度 3 档

| 强度 | 用途 | 调整方向 |
|---|---|---|
| **高（80-95%）** | 牺牲可读性，最大化人味 | 十指讲香全用 / 段落级 checklist 严格 |
| **中（60-80%）** | 平衡人味和可读性（默认）| 选 3-5 手指用 / 段落级 checklist 部分 |
| **低（40-60%）** | 偏可读性，人味作为底色 | 选 1-2 手指用 / 段落级 checklist 宽松 |

### 覆盖机制（用户可手动覆盖）

| 场景 | 覆盖建议 |
|---|---|
| 写"我自己"的故事 | 强制 80%+ Aaron 味 |
| 写"代别人"的故事 | 强制 50%+ L 味（脱 Aaron 暴露） |
| 写"硅谷一手" | 强制 70%+ 不知味 |
| 写"古典哲学" | 强制 70%+ 刘澜味 |
| 写"散文" | 强制 70%+ 和菜头味 |

### 默认推荐流程

```
1. 跑 5 层路由 → 推荐组合
2. 用户查看推荐 → 是否覆盖
3. 不覆盖：使用推荐
4. 覆盖：手动调比例（但需说明理由）
```

## 路由决策的边界

### 路由不能做的事

- 不能 100% 准确（路由是推荐，不是强制）
- 不能替代用户判断（人味有偶然性）
- 不能跨主题硬套（散文+反常识商业 = 不伦不类）
- 不能忽视个体差异（同一作者不同时期味道不同）

### 路由的使用建议

- **新作者**：先跟推荐跑 3 篇，验证手感
- **老作者**：跑 1-2 篇校准，然后自己调
- **跨作者**：用同一主题配不同配方，验证差异
- **回归测试**：用同一作者的历史文，反向配出原配方（验证准确性）
