# 满分产出样本（结构锚点 · better-skill P1-8）

> 本文件是 **结构样板**，不是本技能的真实产出。用于让 Agent 知道「好」长什么样：一份合格交付物应包含哪些段落、每段回答什么问题。
> 使用方式：读完 `../SKILL.md` 后，对照本骨架检查产出是否缺段；**内容须按真实任务填写，禁止照抄本模板文字**。

## 1. 目标与范围（一句话）
- 本次要解决什么问题、交付物是什么、不做什么。

## 2. 输入与前置确认（对应 P0-3 初始对话协议）
- 已向用户确认：计划分 X 步、预期产出 Y、是否开始。
- 前置条件：已侦察过（读文件 / 查状态 / 截图），未猜测任何路径或 ID。

## 3. 执行过程（分阶段，对应 P1-5 退出条件）

|---|---|---|
| 1 | … | 产出齐全、自检通过、无未决阻塞 |
| 2 | … | 同上 |
