# 一页纸教程的认知模型理论依据（V2.0 融合升级版）

本文件说明「一页纸教程」框架背后的认知科学依据，供生成教程时参考校准。V2.0 版本在原有基础上，深度融合了《IPO 能力进阶模型》与《清单体视觉规范》。

---

## 核心框架：WHAT-WHY-HOW-WHEN-WATCH OUT

该五层结构融合了以下四个认知理论：

### 1. 金字塔原理（Pyramid Principle）

Barbara Minto 提出的写作结构：**结论先行，论据支撑**。

- 读者首先看到「是什么」（WHAT），立即建立概念锚点
- 随后「为什么」（WHY）提供动机，激活学习意愿
- 最后「怎么做」（HOW）给出操作路径

对应教程中的体现：一句话定义置于最顶部，步骤置于中部，资源置于底部。

### 2. 认知负荷理论（Cognitive Load Theory）

Sweller（1988）提出：工作记忆容量有限（7±2 个信息块），教学设计需降低外在认知负荷。

| 负荷类型 | 教程中的应对策略 |
| :--- | :--- |
| 内在负荷（概念本身的复杂度） | 提供「大白话版」类比，降低初始理解门槛 |
| 外在负荷（信息呈现方式造成的混乱） | 统一模板结构，避免读者重新适应布局 |
| 相关负荷（深化理解所需的认知投入） | 关键术语表格化，帮助读者主动建构知识图谱 |

### 3. 情境学习理论（Situated Learning）

Lave & Wenger（1991）：知识在具体情境中才能被有效激活和迁移。

- **WHEN 节**（精细化边界定义）直接提供情境锚定，明确失效临界点
- **WATCH OUT 节**（误区纠正）通过反例强化情境判断能力

### 4. IPO 能力进阶模型（Input-Process-Output）

从定性认知到定量死磕，再到肌肉记忆与跨界重构的完整蜕变路径。

- **高阶实战案例（L5/L6 级别）**：普通教程只能教会读者"会用"（L3），而一个贯穿始终的高阶案例能让读者看到"精通"（L5）甚至"泛化创造"（L6）的样子，极大提升教程的价值感和激励效果。

## AI 可读性与清单体视觉规范

为了确保教程不仅人类易读，AI 也能高效解析，V2.0 强制引入了清单体视觉规范：

| 原则 | 实现方式 | 目的 |
| :--- | :--- | :--- |
| 拒绝大段落 | 超过 3 行纯文本必须拆解为列表 | 降低人类视觉疲劳，提高 AI 语义切分准确率 |
| 表格优先 | 对比/分类/层级内容强制使用 Markdown 表格 | 结构化数据比散文更易被 AI 提取键值对 |
| 逻辑单元 | 列表项为主谓宾完整单元，不折行 | 减少 AI 解析时的语义歧义 |
| 视觉重点 | 高频准确使用加粗（**）标注关键概念 | 引导人类视线跳跃阅读，帮助 AI 提取核心实体 |
| 真实 URL | 延伸资源必须是实际访问过的链接 | 避免 AI 生成幻觉链接污染下游任务 |
| 禁止修辞填充 | 不用「非常」「值得注意」等模糊词 | 提高语义密度，降低噪声 |

## 质量自检机制（Checklist 90分基准线）

V2.0 引入了强制的《一页纸教程质量 Checklist》自检机制。该机制将上述认知理论转化为 5 大维度、20 个可量化的检查项。

- **为什么设"高阶案例"为独立检查项？** 这是区分 A 级和 S 级教程的核心分水岭，决定了教程的实战天花板。
- **为什么要求"失效临界点"？** 传统的"适用场景"只告诉读者"能用"，而"失效临界点"告诉读者"绝对不能用"，这才是真正防止误用、保护读者的有效机制。
- **为什么要求"共识提炼"？** 当一个教程涉及多个流派或复杂分类时，读者最容易迷失。强制要求提炼底层共识，是防止"信息轰炸"变成"认知垃圾"的关键防线。

详细的 20 项评分标准请参见 SKILL.md 中的阶段四。
