## 用户指定的目录结构

### 顶层：阿元学习笔记
```
[课程目录]/
└── 阿元学习笔记/          ← 在课程目录下创建，不是课程库的根目录
```
### 子系列目录：主题-子主题 格式
```
阿元学习笔记/
├── 立春-目标管理/
│   ├── 00方法论-立春全年计划-01.md    ← 方法论文件（00前缀）
│   └── 10案例库-立春全年计划-01.md    ← 案例库文件（10前缀）
├── 雨水-学习力/
│   └── ...
```

**命名规则：**
- 子目录：`[节气名]-[主题/子主题]` 格式，如 `立春-目标管理`
- 方法论文件：`00方法论-[课程主题]-[自增后缀].md`，前缀00 = 方法论
- 案例库文件：`10案例库-[课程主题]-[自增后缀].md`，前缀10 = 案例库
- 前缀预留：20=（预留其他类型，如复盘模板/练习工具等）

## 5步法工作流（雪松指定，2026-05-28更新）

1. **分系列** — 把整个课程按节气分成系列课（每个节气 = 一个系列）
2. **建目录** — 在课程目录下创建「阿元学习笔记」目录
3. **建子目录** — 每个系列学完后，在阿元学习笔记下创建 `[节气-主题]` 子目录
4. **写方法论** — 每个系列提炼一个方法论，存为 `00方法论-[课程主题]-[自增后缀].md`
5. **写案例库** — 每个系列收集案例，存为 `10案例库-[课程主题]-[自增后缀].md`
6. **加Obsidian双向链接** — 方法论末尾加「相关案例」，案例库开头加「本案例支撑的方法论」，每个条款和案例之间交叉引用

---

## Obsidian双向链接格式（雪松指定，2026-05-28）

**目的**：方法和案例做关联，支持Obsidian知识库图谱查询。

**格式要求**：

**方法论文件末尾**加「相关案例」链接：
```markdown
## 相关案例

全部案例请参阅：[[10案例库-芒种效能法则-01]]
```

**每个方法论条款下方**加「相关案例」引用：
```markdown
> **相关案例**：[[10案例库-芒种效能法则-01#案例2：小叶的最小正反馈闭环]]
```

**案例库文件开头**加「本案例支撑的方法论」引用：
```markdown
> **本案例支撑的方法论**：[[00方法论-芒种效能法则-01]]
```

**每个案例末尾**加「支撑方法论」引用：
```markdown
> 支撑方法论：[[00方法论-芒种效能法则-01#方法论4：最小正反馈闭环]]
```

**语法**：`[[文件名#章节锚点]]` — #后面是目标章节的标题（Obsidian会自动渲染为可点击链接）。

## 读取策略

**多文件系列处理：**
- 先读公开课（认知），再读实操课（方法）
- 实操课通常2-3个文件，第一个最长
- 每读完一个系列，生成方法论+案例库，再读下一个系列

**单文件系列注意：** 惊蛰系列只有1个公开课文件（324行），读取效率高，1次性读完即可。

**文件读取参数：**
- `read_file` with `limit=200` per batch（雪松指定每200行一报）
- `offset` for continuation
- 汇报节奏：每200行左右一报，或按用户指示

## 批量文件写入技巧

当一个系列有多个文件要写入（方法论+案例库），用`execute_code`一次性写多个文件，比逐个`write_file`效率更高：

```python
content = """文件内容"""
with open("路径1", "w") as f:
    f.write(content)
with open("路径2", "w") as f:
    f.write(content)
```

遇到`.docx`文件需要用`terminal`调用：
```bash
python3 -c "from docx import Document; doc = Document('文件名.docx'); paras = [p.text.strip() for p in doc.paragraphs if p.text.strip()]; print('\n'.join(paras[:200]))"
```
